# LAD / FBD 梯形图自动化：开工计划（**已完成**，规格见 `LADDER_DSL.md`）

> 现状：ST 已全通（37 条能力）。梯形图**内容**是唯一剩下的活，估计 12–20 h，
> 且全程需要真鼠标键盘（会抢前台）。
> 2026-10-25 已完成 P0–P3 与封装：四条能力进表，配方与 DSL 规格落在 `LADDER_DSL.md`。

## 为什么只能走 GUI

- IEC 61131-10 XML 的 `LD`/`FBD`/`IL`/`SFC` 正文全部被静默丢弃（探针 57–65、123），
  `Program` 照样建、`errors=0`，正文是空的 → XML 通道只认 ST。
- 编辑器是自绘画布，UIA 拿不到单元格，`Invoke/SelectionItem/Grid` 模式全 `NULL COM pointer`。
- 所以只能"按键 + 读回"，读回靠 `.gx3` 里的正文 DB。

## 已确定的读回抓手（本轮离线确认）

同一份 FX5U 工程，换语言后正文 DB 会跟着换名：

| 语言（新建对话框 lang） | 标题标记 | 正文 DB |
|---|---|---|
| 0 梯形图 | `[LD]`（待确认） | 待确认（预期 `*_LDDDB.db` 或 `*_LadderDB.db`） |
| 1 ST | `[ST]` | `*_STDB.db`（`StBlocks.data` 明文） |
| 2 SFC | `[SFC]` | `*_SFCDB.db` |
| 3 FBD | `[FBD/LD]` | `*_FBDDB.db` |

其它 DB 三种语言都有：`*_DC.db`（软元件注释）、`*_LabelData.db`、`*_StepInfo.db`（`T_Step`/`T_SourcePos`）。
→ **判据线路已经清楚**：画完 → 转换 → 存盘 → 读正文 DB + `Progress.txt` 错误数，
必要时再读 `T_Step` 拿步数。缺的只是"DB 里梯形图怎么编码"这一层。

## 阶段划分（每阶段都有可判定的门槛）

| 阶段 | 内容 | 估时 | 门槛（必须读到） |
|---|---|---|---|
| P0 | 建一个 `lang=0` 工程，确认标题标记与正文 DB 名/结构 | 0.5 h | 标题含 `[LD]`；DB 名与表结构落进文档 |
| P1 | 画一个最简梯级：`LD X0` → `OUT Y0` | 2–3 h | 转换 0 错、正文 DB 出现该梯级、步数 = 2 |
| P2 | 串/并联：`LD X0 AND X1`、`LD X0 OR X1` 的竖线连接 | 3–4 h | 0 错 + 读回串并联结构 |
| P3 | 应用指令：`MOV K1 D0`、`ADD` 等（F8 应用指令框） | 3–4 h | 0 错 + 读回指令文本 |
| P4 | 分支/标签/跳转/注释（`CJ`、`LABEL`、软元件注释） | 2–3 h | 0 错 + 读回 |
| P5 | 封装能力 `program.write_ladder` + 判据 + 三轮验收 | 1–2 h + 1.5 h×3 | 三轮全绿，进 `registry.yaml` |

**合计 12–20 h**（不含验收 4.5 h）。

## 止损规则（写死，避免无限投入）

- **P1 若 2 小时内做不出"一个触点 + 一个线圈、转换 0 错、读回步数=2"** → 判定 GUI 绘制不可行，
  写进 `docs/UNSUPPORTED.md`（附键盘序列与失败读数），停止。
- P2 若竖线连接始终无法用键盘稳定建立 → 只交付"单梯级（无分支）"能力，并在文档里标范围。
- 任何阶段发现"按键被吞"或"切换语言后画布拒绝输入" → 先取证截图，再决定是否降级。

## 已知的按键资源

GX Works3 梯形图编辑器的常用键（需在 P1 里逐条实测确认，不要凭记忆写死）：

- `F5` 常开触点 / `F6` 常闭触点 / `F7` 线圈 / `F8` 应用指令 / `F9` 竖线 / `F10` 横线
- 弹出软元件输入框后直接键入 `X0` / `Y0` / `D0`，`Enter` 确认，`Esc` 取消
- `Ctrl+↑/↓` 行插入、`Shift+F5` 等需实测
- 转换：`F4`（`转换(B)`），全部转换 `Shift+Alt+F4`

## 开工前需要用户确认

1. 明确说「开始」（按现有约定，未说不动）。
2. 让出机器的时间窗（会抢前台；建议一次给 2–3 h，按阶段推进）。
3. 若中途要停，我用 `job_kill` + 杀 `python.exe`（命令行含 `gxkit run`）收尾，并保证
   `GXW3.exe` 不残留（每轮开始前都 `taskkill /IM GXW3.exe /T`）。
