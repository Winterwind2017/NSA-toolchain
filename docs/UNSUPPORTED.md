# 未打通 / 明确不做

每条都带证据；没有证据的不写在这里。

| 项 | 卡在哪 | 证据 |
|---|---|---|
| `datatype.local_member_access`（**局部**结构体变量按成员名访问） | **机制级堵死**：七条走法全败（private / public / 只写常量 / 整体 Address / DataTypeDecl 前置 / 带成员分配 / 不带成员分配），都是 `程序(...)转换中` 2 错。全局结构体标签正常 → 要按成员名访问就把变量提到全局 | 探针 66/75/76/77/144 |
| `online.write` / `online.read` / `online.monitor` | 需要真实 PLC 或内置模拟器；用户口径是"只做离线"，未验证 | 不做 |
| `ladder.write`（梯形图内容） | 编辑器是自绘控件，UIA 里没有单元格；只能靠菜单/快捷键，无法程序化写网络 | 不做（ST 已覆盖需求） |
| 同会话"新建下一个工程"的批量 | 已有路径的工程再 `Ctrl+N` 会状态漂移（另存为不弹框 / 标题丢路径 / 新建对话框打不开）；`batch.projects` 改成**同一工程连续粘贴 + 菜单另存为**绕过了这一点 | 探针 35 |
| `ladder.import_xml` / `fbd.import_xml`（IEC XML 里的 LD / FBD 正文） | **XML 导入通道只收 ST 正文**。9 次实验全部被**静默丢弃**（0 错、程序不建）：标准 LD（触点+线圈）、最小 `<LD/>`、`xsi:type=Ladder`、三种 PouProperties、属性最小化、只放母线、XSD 序列顺序（母线在前）、以及 IL 正文。同文档换成 ST 立即成功（对照组）。另：没有别的入口 ——「打开其他格式文件」只支持 GX Works2/3、PX Developer、GX Developer；「数据操作」没有导出；XSD 未随装；官方 Sample.xml 只有 ST | 探针 82/85/86/90/91/92/94 |
| `ladder.import_xml` 之外：SFC / FBD / IL 正文 | 与 LD 一样被**静默丢弃**（`xsi:type` 换成 SFC、正规 SFC 片段都试过，程序不建、0 错）。结论：IEC XML 通道**只认 ST 正文** | 探针 123 |
| 工程校验里的「结果一览」表格 | 结果页的 DataGrid **只暴露 1 行**（虚拟化），拿不到全部 17 行；改用状态行 `存在N个不同内容` 做判据 | 探针 140 / `project.check` 读数 |
| `program.edit_existing`（在导航树里打开已有程序再改写） | **做不到稳定**：冷启动时左下面板常停在「连接目标」页、树行矩形与视觉差 ~13px、面板矮时行在可见区外；三个原因都已定位并修（切「导航」标签 / ±20px 扫点 / 最大化+轮询），仍是「这次过、下次不过」→ 不进能力表。改已有程序的稳定路径仍是「用 XML 建好程序」或「粘到当前程序」 | 探针 124b/126~131 + 本轮 12 次冷/热运行 |
