# 交付前检查清单

> AutoCAD 自动化的失败模式是"**执行成功了，图不对**"。
> 按顺序过一遍，每项都要能指出具体数字或文件。

## 事前

- [ ] `acadkit status`：AutoCAD 在跑、`CPROFILE` 是 `<<VANILLA>>`、文档数符合预期
- [ ] `acadkit selftest` 通过（离线自检）
- [ ] 目标能力在 `acadkit list` 里；不在就先 `acadkit registry` 看状态
- [ ] 想清楚这次的判据（实体数？面积？体积？文件签名？）
- [ ] 要导出的目录存在且**上次的产物已删除**（否则"文件存在"可能是旧的）

## 事中

- [ ] 每步之后读一次数量/属性，而不是等最后
- [ ] 三维布尔：句柄在命令**执行前**取好；SUBTRACT 用两组选择集
- [ ] 出图：`BACKGROUNDPLOT` 置 0，出完还原并读回
- [ ] 表格：表头放第 1 行；中文单元格先 `SetCellTextStyle`
- [ ] 命令行：`(vl-cmdf …)`；不要在动过图层表后碰 `-LAYERSTATE`
- [ ] 出现挂死：看 `_scratch/<run>/progress.txt` 的最后一行定位阶段

## 验收

- [ ] 至少一个**可复现的数字**前后对比（实体数/面积/长度/体积/页数）
- [ ] 存盘重开（L4）后数字仍然一致 —— 这是"没白做"的最强证据
- [ ] 文件类：mtime 新、大小下限、文件头（DWG `AC1032` / DXF `  0\r\nSECTION` / PDF `%PDF-`）、PDF 页数
- [ ] 环境未被污染：`CPROFILE` 未变、`TRUSTEDPATHS`/`SECURELOAD` 未变、无 `.sv$`、进程退出
- [ ] 负面对照跑过一次（少属性/错类型/错层 → 判据必须失败）
- [ ] 交付说明里写的是**数字与位置**，不是"已生成"
