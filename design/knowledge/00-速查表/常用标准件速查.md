## 11. 快速计算公式

### 11.1 电机功率

```
P (kW) = T (N·m) × n (rpm) / 9550
```

### 11.2 气缸推力

```
F (N) = π/4 × d² (mm²) × P (MPa) × 1000
```

### 11.3 丝杆转速

```
n (rpm) = v (mm/s) × 60 / P_b (mm)
```

### 11.4 转动惯量（圆柱）

```
J = 1/2 × m × r² = 1/8 × m × d²
```

### 11.5 梁挠度（悬臂梁）

```
δ = F × L³ / (3 × E × I)
```

### 11.6 安全系数

```
n = 强度 / 应力 ≥ 1.5 (一般)
n ≥ 2.0 (重要部件)
n ≥ 3.0 (人身安全相关)
```
