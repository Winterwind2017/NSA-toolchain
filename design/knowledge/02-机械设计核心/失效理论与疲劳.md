# 机械设计核心 — Shigley 设计准则 / 失效理论 / 疲劳

> 来源: Shigley《Mechanical Engineering Design》11th Ed.
> 用途: 非标设备零件强度设计、安全系数确定、疲劳寿命评估

---

## 1. 失效理论总览

| 理论 | 适用材料 | 公式 | 保守度 |
|------|---------|------|--------|
| 最大正应力 (Rankine) | 脆性 | σ₁ ≤ S_ut / n | — |
| 最大剪应力 (Tresca) | 塑性 | τ_max = (σ₁-σ₃)/2 ≤ S_y/(2n) | 中等 |
| 畸变能 (von Mises) | 塑性 | σ' = √(σ₁²-σ₁σ₂+σ₂²) ≤ S_y/n | **推荐** |
| Coulomb-Mohr | 脆性 | σ₁/S_ut - σ₃/S_uc = 1/n | — |

### von Mises 等效应力（最常用）

```
平面应力:  σ' = √(σx² - σx·σy + σy² + 3·τxy²)

三维应力:  σ' = √(½[(σ₁-σ₂)² + (σ₂-σ₃)² + (σ₃-σ₁)²])

纯扭转:    σ' = √3·τ
纯弯曲:    σ' = σ
弯扭组合:  σ' = √(σ² + 3·τ²)
```

**非标应用**: 轴类零件弯扭组合校核、支架多向受力校核。

## 2. 安全系数选取

| 应用场景 | 推荐安全系数 n | 说明 |
|---------|:-------------:|------|
| 静载结构件（机架/底座） | 2.0~3.0 | 载荷确定 |
| 动载结构件（悬臂/连杆） | 3.0~4.0 | 载荷有波动 |
| 精密定位件 | 2.0~2.5 | 变形敏感 |
| 气缸/电机安装座 | 2.0~3.0 | 振动工况 |
| 人身安全相关件 | 5.0~10.0 | 防护罩铰链等 |
| 紧固件（螺栓） | 1.5~2.0 | 预紧力已知 |

## 3. 疲劳设计

### 3.1 持久极限修正（Marin 因子）

```
S_e = k_a · k_b · k_c · k_d · k_e · k_f · S_e'

S_e' = 0.5·S_ut    (钢, S_ut ≤ 1400 MPa)
S_e' = 700 MPa     (钢, S_ut > 1400 MPa)
```

| 因子 | 含义 | 典型值 |
|------|------|--------|
| k_a | 表面状态 | 机加工 0.7~0.9, 磨削 0.9~1.0 |
| k_b | 尺寸因子 | d≤8mm: 1.0; d=50mm: 0.81 |
| k_c | 载荷因子 | 弯曲 1.0, 轴向 0.85, 扭转 0.59 |
| k_d | 温度因子 | <350°C: 1.0 |
| k_e | 可靠性因子 | 99%: 0.814, 99.9%: 0.753 |
| k_f | 其他（腐蚀/镀层） | 视情况 |

### 3.2 疲劳失效准则（Haigh 图）

```
修正 Goodman:  σ_a/S_e + σ_m/S_ut = 1/n     ← 工业最常用
Soderberg:     σ_a/S_e + σ_m/S_y  = 1/n     ← 最保守
Gerber:        n·σ_a/S_e + (n·σ_m/S_ut)² = 1  ← 延性材料最贴合实验
ASME 椭圆:     (n·σ_a/S_e)² + (n·σ_m/S_y)² = 1
Langer 屈服线: σ_a + σ_m = S_y / n           ← 首周期屈服检查
```

### 3.3 应力集中与缺口敏感

```
K_f = 1 + q·(K_t - 1)

q = 1 / (1 + √a / r)    (Neuber 常数 a 查表)

典型 K_t 值:
  轴肩圆角 r/d=0.02:  K_t ≈ 2.5~3.0
  键槽:               K_t ≈ 2.0~2.5
  螺纹根部:           K_t ≈ 3.0~4.0
  横孔:               K_t ≈ 2.5~3.5
```

### 3.4 累积疲劳损伤（Miner 法则）

```
Σ(n_i / N_i) = 1    (当累积损伤 = 1 时失效)

n_i: 第 i 级应力幅的循环次数
N_i: 第 i 级应力幅对应的疲劳寿命
```

## 4. 轴设计（Shigley 方法）

```
轴径估算（弯扭组合 + 疲劳）:

d = [ (16·n/π) · √( (2·K_f·M_a/S_e)² + 3·(K_fs·T_m/S_y)² ) ]^(1/3)

其中:
  M_a = 交变弯矩幅值
  T_m = 平均扭矩
  K_f = 弯曲疲劳应力集中系数
  K_fs = 扭转疲劳应力集中系数
  S_e = 修正持久极限
  S_y = 屈服强度
  n = 设计安全系数
```

**挠度校核**: 轴在齿轮/带轮处的挠度 ≤ 0.01·m（模数）或 0.001·d（轴承处）

## 5. 螺栓连接设计

```
预紧力:  F_i = 0.75·A_t·S_p    (非永久连接)
         F_i = 0.90·A_t·S_p    (永久连接/密封)

A_t = 螺纹应力面积 = (π/4)·((d_p + d_r)/2)²

螺栓刚度:  k_b = A_b·E / L
被连接件刚度: k_m ≈ 0.5·k_b (经验)

外载分担:  ΔF_b = C·P    (C = k_b/(k_b+k_m))
           ΔF_m = (1-C)·P

防松条件:  F_i - (1-C)·P > 0    (接合面不分离)

疲劳校核:  σ_a = C·P / (2·A_t)
           用 Goodman 准则校核
```

| 螺栓规格 | A_t (mm²) | S_p (MPa, 8.8级) | 推荐预紧力 (kN) |
|---------|-----------|-----------------|----------------|
| M6 | 20.1 | 600 | 9.0 |
| M8 | 36.6 | 600 | 16.5 |
| M10 | 58.0 | 600 | 26.1 |
| M12 | 84.3 | 600 | 37.9 |
| M16 | 157 | 600 | 70.7 |

## 6. 焊接接头设计

```
角焊缝有效厚度:  a = 0.707·h    (h = 焊脚尺寸)

焊缝许用剪应力:  [τ] = 0.4·S_y (母材)

焊缝强度校核:  τ = F / (a·L) ≤ [τ]

常见焊缝许用应力 (Q235):
  对接焊缝 [σ] = 160 MPa
  角焊缝 [τ] = 100 MPa
```
