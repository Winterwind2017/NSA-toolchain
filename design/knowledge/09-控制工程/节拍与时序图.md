# 设备节拍与时序图

> 线索: B站 BV13t896UEWL P13《高工必备能力：时序图》片头大纲（动作流程 / 串并联 / 完成时间），案例装配为苹果喷码设备 `GC01-40-00`。该集无字幕，口播公式未逐字收录；正文按非标高工实务补全，不把 SW 逛模型当知识。
> 计算: `design_calc.cycle_time`

用户一提节拍、UPH、时序、动作流程、串并联，先读本文再算，不要把所有动作时间直接相加。

---

## 1. 为什么时序图是高工能力

非标设备不是“零件堆完就能量产”。电气按动作写程序，机构按行程选型，两者必须先在同一张时序图上对齐：

- 机械看到的是气缸/模组能不能在窗口内走完
- 电气看到的是谁先动、谁等传感器、谁能并行
- 项目经理看到的是 CT 能不能达标

**错法**：方案阶段只报一个“大概 6 秒”，详细设计后再发现压装保压就要 2 秒，整线超节拍。
**对法**：需求分析后立刻出动作流程 + 时序图，再决定气缸还是伺服、几工位、要不要并联。

## 2. 三步法（本集精华）

### 2.1 设备的动作流程

先写**工艺故事**，再写轴。每个工件从进到出，按工位列出最小动作单元：

| 字段 | 写什么 | 例子（喷码/贴标类） |
|------|--------|---------------------|
| 工位 | 物理位置 | 上料 / 定位 / 喷码 / 下料 |
| 动作名 | 一个执行器的一次单向动作 | 挡停伸出、夹紧、喷头下降 |
| 执行器 | 气缸/伺服/阀/相机 | φ32 气缸、400W 模组 |
| 触发条件 | 谁允许它开始 | 到位光电 ON、上一动作完成 |
| 完成判据 | 谁证明它结束 | 磁性开关、位置完成、延时 |
| 互锁 | 绝对不能同时发生 | 喷头下降 vs 产品流走 |

规则：

1. 一个动作只对应**一个执行器的一个方向**（伸出/缩回分开写）
2. 检测、保压、吹气、等待稳定都要单独成行，不要藏在“压装”里
3. 复位动作必须写进同一张图，否则 CT 会漏掉回程

### 2.2 动作的串联和并联

| 关系 | 时间怎么算 | 什么时候用 |
|------|------------|------------|
| 串联 | `t = t1 + t2` | 有互锁、有先后、同一空间会撞 |
| 并联 | `t = max(t1, t2)` | 空间不干涉、传感器独立、电气可同时输出 |
| 部分重叠 | `t = t1 + t2 - overlap` | 提前启动、跟随、飞行喷码 |

并联的前提（少一条就不能并）：

- 运动包络不干涉（含软管、相机视野）
- 工件已被可靠约束
- 两端都有独立完成信号
- 故障时能各自安全复位

**优化节拍的第一刀永远是并联，不是把气缸换成伺服。** 伺服只解决“这段必须很快或必须可控”的动作。

### 2.3 动作的完成时间

每个动作的时间不要拍脑袋，按执行器拆：

```
气缸单向时间 ≈ 行程 / 平均速度 + 阀响应 + 缓冲末端
伺服时间     = 加速 + 匀速 + 减速 + 到位稳定
工艺时间     = 保压 / 喷码 / 拍照 / 固化 / 冷却（不可压缩）
辅助时间     = 通信、换型、吹屑、等待上游
```

经验量级（方案阶段够用，详细设计用样本曲线校核）：

| 类型 | 常用区间 | 备注 |
|------|----------|------|
| 气缸 50–100mm | 0.15–0.40 s | 排气节流、带负载取偏慢值 |
| 电磁阀响应 | 0.015–0.040 s | 阀岛远、气管长会再加 |
| 伺服短行程定位 | 0.08–0.25 s | 含稳定；高精度再加 50–100ms |
| 光电/接近确认 | 0.01–0.03 s | 滤波时间要算进去 |
| 工业相机拍照 | 0.05–0.20 s | 曝光+取图+算法 |
| 喷码/打印 | 0.05–0.50 s | 看内容长度和飞行速度 |
| 压装保压 | 0.20–2.00 s | 常常是瓶颈，并联也消不掉 |

安全余量：方案阶段 **×1.15~1.25**。客户 CT 很紧时先找并联，再压缩工艺时间，最后才加钱换执行器。

## 3. 节拍计算公式

```
单站 CT = 关键路径时间 + 复位/让路时间 + 余量
UPH     = 3600 / CT × 并行工位数 × 良率
线体 CT = max(各站 CT, 物流节拍)
```

关键路径 = 从“允许进料”到“允许出料”的最长不可并行链。

反例（skill 里旧的错误口径，已作废）：

> 节拍 = 所有动作时间之和

这会把已经并联的夹紧、定位、相机预触发重复加进去，CT 虚高，后面选型全部偏大。

## 4. 时序图画法

横向时间，纵向动作。每个动作一条带：高电平 = 动作中，上升沿 = 启动，下降沿 = 完成。

必备标注：

1. 时间轴刻度（建议 0.1s）
2. 启动条件（传感器/上位允许）
3. 完成条件（磁性开关 / 位置完成 / TON）
4. 并联括号或同一时间窗的对齐线
5. 干涉禁区（两带不能重叠处打叉）
6. CT 窗口（一条竖线标客户节拍）

文本草图（方案阶段即可）：

```
t(s)    0    0.3   0.6   0.9   1.2   1.5   1.8
进料挡停 ████
夹紧          ████████
定位          ████
喷头下降           ██████
喷码                    ████
喷头上升                     ████
松开                               ████
放行                                    ████
```

上图里夹紧与定位并联，喷码是工艺时间，不能和喷头运动重叠。

电气交付物：同一张图给 PLC 写步序 / 顺序功能图。机械交付物：每个带对应一个执行器型号和行程。

## 5. 案例骨架：喷码/贴标类

P13 演示机是多工位喷码装配（零件号前缀 `QC01-`、铝型材机架、多个气缸杆）。这类设备的典型关键路径：

```
来料到位 → 挡停/定位 → (夹紧 ∥ 读码/触发) → 喷头到位 → 喷码 → 喷头让开 → 松开 → 放行
```

常见翻车：

| 现象 | 根因 | 改法 |
|------|------|------|
| 喷码拖影 | 喷头未稳定或产品还在漂 | 加稳定时间，或改飞行喷码 |
| CT 超了但机构不忙 | 挡停和夹紧串在一起 | 定位未完成前预夹紧（确认不干涉） |
| 偶尔漏喷 | 完成信号用延时而不是传感器 | 加到位检测，延时只做备份 |
| 复位比工作还慢 | 回程节流过死、阀选小了 | 回程单独算进 CT，加大阀或改差动 |

## 6. 设计流程中的插入点

| 阶段 | 必须产出 |
|------|----------|
| 需求分析 | 客户 CT、UPH、是否允许并联工位 |
| 概念方案 | 动作表 + 时序草图 + 关键路径 CT |
| 详细设计 | 每个动作的执行器时间校核 |
| 联调 | 用示波器/PLC 轨迹回填实际时间，改图 |

客户改节拍时，先改时序图，再改模型。不要先改气缸行程再回头发现并联关系变了。

---

## 7. 反模式

1. 只写“工作”，不写复位
2. 用一个总延时代替完成信号
3. 空间会撞还硬并联
4. 把不可压缩的保压/固化当成能靠伺服“抢回来”的时间
5. 多工位线体用单站动作和当整线 CT
