# 控制工程基础 — 伺服调参 / PID / 气动回路

> 来源: 雷赛/安川/三菱伺服调试手册、Ogata《现代控制工程》、非标调试经验
> 用途: 伺服系统调试、PID 参数整定、气动回路设计

---

## 1. 伺服三环控制结构

```
位置环 (最外)  →  速度环 (中间)  →  电流环 (最内)
   P 控制          PI 控制           PI 控制
   带宽最低        带宽中等          带宽最高
```

### 1.1 各环功能

| 环路 | 控制方式 | 反馈源 | 调节参数 | 作用 |
|------|---------|--------|---------|------|
| 电流环 | PI | 电流传感器 | KCP, KCI | 转矩控制，响应最快 |
| 速度环 | PI | 编码器 | KVP, KVI | 速度跟随，抑制扰动 |
| 位置环 | P | 编码器 | KPP | 位置精度，定位时间 |

### 1.2 带宽关系

```
电流环带宽 > 速度环带宽 > 位置环带宽

经验比例:
  速度环带宽 ≈ 电流环带宽 / 3~5
  位置环带宽 ≈ 速度环带宽 / 3~4
```

## 2. 伺服增益调试步骤

### 2.1 调试原则

```
1. 先机械后电气 — 确保机械无松动/共振
2. 从内向外 — 电流环 → 速度环 → 位置环
3. 从小到大 — 增益逐步增大，观察响应
4. 积分从大到小 — 积分时间常数逐步减小
```

### 2.2 速度环调试

```
步骤:
1. 位置环增益设为最小值
2. 速度积分时间 KVI 设为较大值 (如 50ms)
3. 逐步增大速度比例增益 KVP
4. 出现啸叫/振动时停止，回调 20~30%
5. 逐步减小 KVI，消除稳态误差
6. 若仍有高频振动 → 启用低通滤波器/陷波器
```

### 2.3 位置环调试

```
步骤:
1. 速度环稳定后开始
2. 逐步增大位置比例增益 KPP
3. 观察定位时间和超调
4. 出现抖动时回调
5. 引入速度前馈 → 减小跟踪误差/超调
```

### 2.4 典型参数范围

| 参数 | 典型范围 | 说明 |
|------|---------|------|
| KVP (速度比例) | 10~50 Hz | 越大响应越快 |
| KVI (速度积分) | 5~50 ms | 越小消除误差越快 |
| KPP (位置比例) | 50~200 1/s | 越大定位越快 |
| 速度前馈 | 0~100% | 减小跟踪误差 |
| 低通滤波器 | 1~5 ms | 抑制高频共振 |

### 2.5 共振抑制

```
机械共振频率 f_r 通常在 100~500 Hz

抑制方法:
1. 转矩低通滤波器: 截止频率 = 1/(2π·T_f)
   T_f = 1~5ms → 截止 30~160 Hz
2. 陷波器: 设定在共振频率处
3. 降低增益: 牺牲响应速度换稳定
```

## 3. PID 控制基础

### 3.1 PID 公式

```
u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de(t)/dt

Kp: 比例增益 — 减小误差，过大则振荡
Ki: 积分增益 — 消除稳态误差，过大则超调
Kd: 微分增益 — 抑制超调/预测，过大则噪声敏感
```

### 3.2 整定方法

| 方法 | 步骤 | 适用 |
|------|------|------|
| 试凑法 | 先 P → 加 I → 加 D | **非标最常用** |
| Ziegler-Nichols | 临界振荡法 | 有模型的场合 |
| 自动整定 | 驱动器自整定功能 | 伺服驱动器 |

### 3.3 试凑法口诀

```
参数整定找最佳，从小到大顺序查
先是比例后积分，最后再把微分加
曲线振荡很频繁，比例度盘要放大
曲线漂浮绕大弯，比例度盘往小扳
曲线偏离回复慢，积分时间往下降
曲线波动周期长，积分时间再加长
曲线振荡频率快，先把微分降下来
```

## 4. 气动回路设计

### 4.1 基本回路

| 回路 | 元件 | 功能 |
|------|------|------|
| 单作用控制 | 3/2 阀 + 弹簧缸 | 夹紧/吹气 |
| 双作用控制 | 5/2 阀 + 双作用缸 | **最常用** |
| 速度控制 | 排气节流阀 | 调节气缸速度 |
| 中停控制 | 5/3 中封阀 | 中间位置保持 |
| 缓冲回路 | 液压缓冲器 | 高速末端缓冲 |
| 互锁回路 | 双压阀/梭阀 | 安全联锁 |

### 4.2 速度控制原则

```
水平安装 → 排气节流调速 (出口节流)
垂直提升 → 进气节流调速 (入口节流)
末端平稳 → 带缓冲气缸 + 排气节流
```

### 4.3 气源处理

```
三联件配置:
  过滤器: 5μm (一般) / 0.3μm (精密阀)
  减压阀: 设定 0.4~0.6 MPa
  油雾器: 仅对有油润滑元件使用 (无油缸禁止加)

管路设计:
  主管: ≥ Φ12
  支管: 按气缸选型
  阀到缸: 尽量短 (< 1m)
```
