## 1. 齿轮传动设计

### 1.1 基本参数

| 参数 | 符号 | 公式/说明 |
|------|------|----------|
| 模数 | m | 标准值: 1, 1.25, 1.5, 2, 2.5, 3, 4, 5, 6, 8, 10 |
| 齿数 | z | 小齿轮 z₁ ≥ 17 (避免根切) |
| 分度圆直径 | d | d = m·z |
| 齿顶圆直径 | d_a | d_a = d + 2·m |
| 齿根圆直径 | d_f | d_f = d - 2.5·m |
| 中心距 | a | a = m·(z₁+z₂)/2 |
| 传动比 | i | i = z₂/z₁ = n₁/n₂ |
| 齿宽 | b | b = φ_d · d₁ (φ_d = 0.8~1.4) |

### 1.2 弯曲强度校核（Lewis 简化公式）

```
σ_F = F_t · K_F / (b · m · Y_F)

F_t = 2·T₁ / d₁          (切向力)
K_F = K_A · K_V · K_Fβ    (载荷系数, 一般取 1.3~1.6)
Y_F ≈ 0.154 - 0.912/z     (Lewis 齿形系数, 简化)

校核条件: σ_F ≤ [σ_F]
安全系数: S_F = [σ_F] / σ_F ≥ 1.2~1.4
```

### 1.3 接触强度校核（Hertz 公式）

```
σ_H = Z_E · √(F_t · K_H / (b · d₁) · (u+1)/u)

Z_E = 189.8 √MPa  (钢对钢)
K_H = K_A · K_V · K_Hβ    (接触载荷系数)
u = z₂/z₁                  (齿数比)

校核条件: σ_H ≤ [σ_H]
安全系数: S_H = [σ_H] / σ_H ≥ 1.1~1.15
```

### 1.4 许用应力参考

| 材料 | 热处理 | [σ_F] (MPa) | [σ_H] (MPa) |
|------|--------|:-----------:|:-----------:|
| 45钢 | 调质 | 180~220 | 550~650 |
| 40Cr | 调质+表面淬火 | 250~320 | 900~1100 |
| 20CrMnTi | 渗碳淬火 | 300~400 | 1200~1500 |

### 1.5 设计准则

- **闭式软齿面** (HB≤350): 先按接触强度定 d₁，再校核弯曲
- **闭式硬齿面** (HB>350): 先按弯曲强度定 m，再校核接触
- **开式齿轮**: 只按弯曲强度设计，m 放大 10~15%

## 2. 带传动设计

### 2.1 V 带选型

```
计算功率:  P_c = K_A · P    (K_A = 工况系数 1.0~1.5)
带型选择:  根据 P_c 和小带轮转速 n₁ 查选型图
带轮基准直径: d_d1 ≥ d_dmin (查表)
带速:  v = π·d_d1·n₁ / 60000    (推荐 5~25 m/s)
中心距:  a₀ ≈ 0.7·(d_d1+d_d2) ~ 2·(d_d1+d_d2)
带长:  L_d ≈ 2·a₀ + π·(d_d1+d_d2)/2 + (d_d2-d_d1)²/(4·a₀)
带根数:  z = P_c / [(P₀+ΔP₀)·K_α·K_L]
```

### 2.2 同步带选型

```
节距选择:  根据功率和转速查选型表
带宽:  b = b₀ · √(P_c / P₀)    (b₀ = 基准带宽)
齿数:  z = L_p / p    (L_p = 节线长, p = 节距)
```

| 同步带型号 | 节距 p (mm) | 适用功率范围 |
|-----------|:-----------:|------------|
| 3M | 3 | <0.5 kW |
| 5M | 5 | 0.5~3 kW |
| 8M | 8 | 3~15 kW |
| 14M | 14 | 15~50 kW |

## 3. 凸轮机构

### 3.1 运动规律选择

| 运动规律 | 特点 | 适用场景 |
|---------|------|---------|
| 等速 | 刚性冲击 | 低速轻载 |
| 等加速等减速 | 柔性冲击 | 中速 |
| 余弦加速度 | 柔性冲击 | 中速 |
| 正弦加速度 | 无冲击 | **高速推荐** |
| 3-4-5 多项式 | 无冲击 | 高速精密 |

### 3.2 基圆半径

```
r₀ ≥ r_s + √(v_max/(ω·tan[α]))

r_s = 滚子半径
α = 许用压力角 (推程 ≤ 30°, 回程 ≤ 70°~80°)
v_max = 从动件最大速度
ω = 凸轮角速度
```

## 4. 连杆机构

### 4.1 四杆机构类型判定（Grashof 条件）

```
l_max + l_min ≤ l' + l''  →  存在曲柄

最短杆为机架 → 双曲柄
最短杆为连架杆 → 曲柄摇杆
最短杆为连杆 → 双摇杆
```

### 4.2 急回特性

```
行程速比系数:  K = (180° + θ) / (180° - θ)
θ = 极位夹角
```

## 5. 非标常用传动方案速查

方案决策（何时用丝杆/带/齿条/链条/分割器）见 `03-机构设计/传动元件选型.md`，用 `transmission.recommend_drive`。

| 需求 | 推荐方案 | 传动比范围 | 效率 |
|------|---------|:---------:|:----:|
| 精确直线运动 | 伺服+丝杆 | — | 0.90~0.95 |
| 高速直线运动 | 伺服+同步带 | — | 0.95~0.98 |
| 大扭矩旋转 | 伺服+行星减速机 | 3~100 | 0.95~0.97 |
| 分度定位 | DD马达/凸轮分割器 | — | 0.90+ |
| 长距离输送 | 电机+链条/皮带 | — | 0.92~0.96 |
| 垂直升降 | 电机+丝杆/气缸 | — | 0.85~0.95 |
