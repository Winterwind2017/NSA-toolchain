# 非标齿轮设计与选型

> 线索: B站 BV13t896UEWL P12《齿轮的设计》片头脑图：作用、失效、材质、热处理、设计、选型、插件、参数、齿形分类。该集约 32 min 且无字幕，不收录口播型号表；正文按非标方案决策补全。
> 计算: `design_calc.gear`
> 弯曲/接触强度公式细节仍见同目录 `传动设计.md` §1。齿条路线见 `传动元件选型.md`。减速机见 `reducer`。

非标默认：**能买就不画**。伺服轴优先行星/谐波减速机，不要为了“显得专业”自制两级开式齿轮箱。

---

## 1. 作用：齿轮在设备里干什么

- 定传动比、换向、分路扭矩  
- 平行轴最常用；相交轴用锥齿；交错大速比用蜗轮（可自锁，效率低）  
- 直线长行程用齿轮齿条（先 `transmission.recommend_drive`）

开式齿轮暴露在机架上：要罩、要润滑、要防尘。闭式（减速机箱）寿命和噪音都好一个档。

---

## 2. 失效形式 → 设计时防什么

| 失效 | 看起来 | 主因 | 对策 |
|------|--------|------|------|
| 磨损 | 齿变薄、侧隙变大 | 开式、没油、粉尘 | 罩+脂/油，或改闭式减速机 |
| 点蚀 | 节线附近麻点 | 接触疲劳 | 硬齿面、够大的 d 和 b |
| 塑性变形 | 齿顶挤出、压溃 | 过载、材料太软 | 加大模数或换 40Cr/渗碳 |
| 断齿 | 齿根裂 | 弯曲疲劳或冲击 | 加大 m，根部圆角，别根切 |
| 胶合 | 齿面撕粘 | 高速油膜破裂 | 降 v、更好的油、斜齿 |

软齿面闭式：**先按接触定尺寸，再校弯曲**。硬齿面：**先按弯曲定模数，再校接触**。开式：只按弯曲，模数再放大约 10%。

## 3. 材质与热处理

片头按载荷分档（与 `04-材料与热处理` 一致）：

| 载荷 | 材料 | 处理 |
|------|------|------|
| 轻 | 45 | 调质，或齿面淬火 |
| 中 | 45 或 40Cr | 调质 + 表面淬火 |
| 重 | 20CrMnTi 等低碳合金 | 渗碳淬火 |
| 轻载安静、无油或少油 | POM | 吸湿小，尺寸稳 |
| 轻载、冲击略大 | PA66 | 吸湿大，潮湿环境尺寸漂 |

塑料齿轮不要跟钢齿轮当重载对滚；钢对 POM 可以降噪，按厂家许用扭矩，不要套钢的 Lewis 许用值。

小齿轮比大齿轮硬一点、齿面耐磨一点，磨损集中在好换的小轮上。

## 4. 先选型还是先设计

```
已知: 转速、扭矩（或功率）、传动比
  → 能落进米思米/KHK 等样本中心距？ → 选型（查表买）
  → 中心距、变位、非标齿数比样本没有 → 设计（算 m、z、b，再校核）
  → 其实是伺服减速 → 停，改 reducer.recommend_type
```

选型三步（片头）：已知条件 → 初定材质和模数量级 → **查样本**。不要先在 SolidWorks 里拉一个齿轮再反算。

片头量级例（不是订货型号）：`i=2`，小轮 800 rpm / 大轮 400 rpm，`z=17/34`，`m=2`，齿宽小轮 40 / 大轮 30，功率 500 W。小轮齿宽略大于大轮，对中误差时接触仍落在大轮全齿宽上。

## 5. 设计计算顺序

1. 扭矩 `T = 9550 · P(kW) / n(rpm)`（或由负载反算）  
2. 选材料 → 弹性系数 / 许用应力  
3. 传动比 → 中心距和直径量级  
4. 齿数：小轮 **z₁ ≥ 17**（标准变位，防根切）；大轮 `z₂ = i·z₁`  
5. 模数取标准系列：1 / 1.25 / 1.5 / 2 / 2.5 / 3 / 4 / 5 / 6 …  
6. 齿宽 `b ≈ (0.8~1.4)·d₁`，小轮略宽  
7. 校核弯曲疲劳（`gear.bending_check` / `传动设计.md`）  
8. 校核圆周速度 `v = π·d·n / 60000`（m/s）  
   - 直齿一般希望 **v < 6 m/s**（片头校核口径）  
   - 再高用斜齿、提高精度、上油浴或改减速机  

几何：`d = m·z`，`d_a = d+2m`，`d_f = d-2.5m`，`a = m·(z₁+z₂)/2`（标准变位）。

斜齿：重合度高、更静音，但有轴向力 `F_a = F_t · tanβ`，轴承必须按轴向力选。锥齿、蜗轮按样本，不要现场发明锥角。

## 6. 齿形分类（非标够用）

| 类型 | 轴关系 | 特点 |
|------|--------|------|
| 直齿圆柱 | 平行 | 便宜、无轴向力，速度不宜高 |
| 斜齿圆柱 | 平行 | 稳、静音，有轴向力 |
| 内齿 | 平行 | 行星内齿圈、空间紧 |
| 锥齿 | 相交 | 换向 90° |
| 蜗轮蜗杆 | 交错 | 大速比、可自锁、效率低、发热 |
| 齿条 | 转动变直线 | 长行程，要消隙 |

精度：搬运 8 级；要安静或反复换向 7 级；对位轴优先减速机，不要开式 6 级齿轮硬扛。

---

## 7. 插件与图纸

SolidWorks Toolbox / 齿轮插件只做 **生成齿形**，在 m、z、b、变位锁定之后。插件里的“强度/跨齿/校核”可当验算，不能代替 `gear` 计算和样本许用扭矩。

出图至少写：模数、齿数、齿宽、变位系数、精度等级、热处理、跨齿距或公法线（检验用）。键槽、挡圈槽按轴设计，不要齿盘悬臂太长。

---

## 8. 反模式

- 伺服轴自制开式齿轮箱，却买得起行星减速机  
- z₁=12 还不做变位，根切后再怪断齿  
- 直齿 3000 rpm 还按“看起来能转”  
- 塑料齿轮套钢的许用应力  
- 先插件拉齿，中心距对着装配“差不多”  
- 齿轮齿条不消隙还要 ±0.05 mm 换向精度  

边界：传动路线用 `transmission`；箱体减速用 `reducer`；自己做一对平行轴齿轮才进本文。
