# 电磁阀与气动控制元件选型

> 线索: B站 BV13t896UEWL P11《电磁阀的选型》片头脑图「3.3 气动控制元件的选型与应用」。该集无字幕；正文按 SMC/亚德客惯例 + 非标现场补全。案例装配：在线式自动贴隔膜机阀岛。
> 计算: `design_calc.pneumatic.valve_select`

用户要选阀、阀岛、中封/中泄、单电/双电时读本文。先定气缸动作，再定阀，不要先抄一个 SY5120。执行器种类（标准/无杆/手指/真空）见 `05-标准件选型/气动元件选型.md`。

---

## 1. 先分清三类气动控制元件

P11 把气动控制拆成三族，选型时不要混：

| 族 | 管什么 | 典型件 | 谁来选 |
|----|--------|--------|--------|
| 方向控制阀 | 气往哪走 | 电磁阀、手动阀、梭阀、双压阀、快排阀 | 机械 + 电气 |
| 流量控制阀 | 气走多快 | 排气节流、单向节流 | 机械调速 |
| 压力控制阀 | 气压多高 | 减压阀、溢流、顺序阀 | 气源与工位分压 |

电磁阀只是方向阀里给 PLC 用的那一种。手动阀（如 4HV210/4HV230）给调试、紧急排气、气源总开，不能拿来当节拍执行器。

## 2. 电磁阀 9 步选型（本集精华）

按这个顺序走，漏一步就会在现场改单。

### ① 选系列

先定品牌系列，再填规格。非标常用：

| 场景 | 优先系列 | 原因 |
|------|----------|------|
| 多工位设备、阀多 | 阀岛：SMC SY3000/5000、亚德客 4V210 集装、Festo VTUG | 走线短、换阀快、带总线 |
| 单缸、散阀 | SMC SY/VQ、亚德客 4V | 便宜、好买 |
| 阀必须挨着缸 | 气缸带阀 / 板式小阀 | 管长短、节拍快 |
| 粉尘/水汽 | 防护型或箱内阀岛 | 线圈和滑阀怕脏 |

同一台设备尽量只保留 **一个系列**，备件和气管接头才统一。

### ② 选动作方式（通路）

| 阀 | 口数/位置 | 配什么执行器 | 停电默认 |
|----|-----------|--------------|----------|
| 2/2 | 通断 | 吹气、真空破坏、气源总阀 | 常闭更安全 |
| 3/2 | 单作用 | 弹簧缸、真空发生器、单点吹气 | 单电控回弹簧位 |
| 5/2 单电 | 双作用 | **最常用双作用缸** | 失电回弹簧位（通常缩回） |
| 5/2 双电 | 双作用 | 要保持最后位置、省电 | 失电保持（靠定位销/摩擦） |
| 5/3 中封 | 双作用中停 | 中途停、防坠落辅助 | 两线圈都掉电则封闭 |
| 5/3 中泄 | 双作用放松 | 要能手推、对中、卸力 | 中位两腔通排气 |
| 5/3 中压 | 少用 | 两腔同时进气锁死 | 中位两腔进气 |

口诀：

- 只要往复、不要中停 → **5/2**
- 要中途停且不能被人推走 → **5/3 中封**
- 要中途停但还要能手扳对位 → **5/3 中泄**
- 垂直负载只靠中封阀锁是不够的，还要气动保压阀或机械锁

### ③ 选密封形式

| 密封 | 特点 | 什么时候用 |
|------|------|------------|
| 软密封（橡胶滑阀） | 泄漏小、便宜、怕脏 | 常规设备 |
| 金属密封 | 耐温、寿命长、微漏可接受 | 高温、高频 |
| 先导式 | 流量大、最低气压约 0.15 MPa | 缸径 ≥ 16 的主流阀 |
| 直动式 | 零压可动作、流量小 | 真空、低压、小口径 |

先导阀在气源掉到最低先导压以下会“有电不动”，调试时先查气压再查线圈。

### ④ 选控制方式

| 控制 | 含义 | 选用 |
|------|------|------|
| 单电控（弹簧复位） | 一进一出，失电回位 | 默认；安全回缩/松开 |
| 双电控 | 两个线圈互锁，脉冲即可 | 要保持、节拍里不想一直带电 |
| 内部先导 | 用主气路自己的气 | 常规 |
| 外部先导 | 另接先导气 | 真空、低压主气路 |

双电控必须在 PLC 里做**互锁**（两个线圈不能同时 ON），并加最短脉冲（约 50–100 ms）。

### ⑤ 选电气规格

非标默认：**DC24V，正负切换型线圈，PLC 晶体管输出 + 续流二极管（阀自带或端子排加）**。

核对这几项，不要只写“24V”：

- 电压：DC24V（少用 AC220，柜内才出现）
- 功率：阀岛单阀约 0.4–1.0 W，散阀 1–3 W；算 PLC 输出点数和开关电源容量
- 指示灯：要，方便现场看谁在动
- 手动Override：要，调试用；量产可加防护盖防误碰
- 插头：阀岛用扁平电缆/总线；散阀用插片或 M8

线圈两端必须有续流。没有的话 PLC 输出和邻近传感器会一起误动作。

### ⑥ 选配管形式

| 形式 | 适用 |
|------|------|
| 阀岛 / 集装板 | 阀 ≥ 4 只，统一进气、统一排气消声 |
| 底板配管 | 阀可热插拔，气管在底板 |
| 阀体配管 | 散阀，气管直接插阀 |
| 管接头 | 快插 Φ4/6/8，少用螺纹活接除非振动大 |

P11 案例（贴隔膜机）是一排带蓝帽手动Override 的阀岛，这是正确默认：多工位设备先画阀岛，再给每个工位编号，和电气 I/O 表同一套名字。

### ⑦ 选配管口径

口径看**气缸耗气**，不看阀长得大不大。

| 缸径 | 气管 | 阀接管常见 |
|------|------|------------|
| ≤16 | Φ4 | M5 / Φ4 |
| 16–32 | Φ6 | 1/8 / Φ6 |
| 32–63 | Φ8 | 1/4 / Φ8 |
| 63–100 | Φ10 | 1/4–3/8 |
| ≥100 | Φ12 | 3/8 |

阀到缸 > 1 m：先放大一号管，或把阀放到缸旁。消声器也要够大，否则排气背压把缸“憋慢”。

### ⑧ 计算最大耗气量

用 `pneumatic.air_consumption` 把**同一秒会同时动作的气缸**加起来，不是把设备上所有缸加总。

```
同时耗气量 = Σ(同时动作缸的单次容积 × 压缩比 / 该动作时间)
气源与阀岛总管按同时耗气量选，再留 20–30%
```

阀的流通能力（Cv / sonic conductance）必须大于这段峰值。样本对不上时：同系列往上加一档（SY3000→SY5000）。

### ⑨ 用一个工位当例题收口

每个阀在图纸上写清这 7 个数，才算出过：

1. 控制哪个缸、行程、缸径  
2. 阀型（5/2 单电 / 5/3 中封…）  
3. 电压与 I/O 点名  
4. 管径与阀到缸长度  
5. 同时动作的伙伴缸  
6. 失电安全位置  
7. 节流装在哪（排气侧）

## 3. 方向阀里的“逻辑阀”（常被漏选）

| 阀 | 逻辑 | 用法 |
|----|------|------|
| 梭阀 | P1 OR P2 → A | 两处都能供气：自动 + 手动、两工位共用吹气 |
| 双压阀 | P1 AND P2 → A | 互锁：两条件同时满足才夹紧 |
| 快速排气阀 | 缸口就地排气 | 大缸回程要快、管又长 |

梭阀和双压阀不是电磁阀的替代品，是回路里的安全/便捷件。P11 单独把它们列在“气体流通方向”下，就是怕只记 5/2。

## 4. 流量阀与压力阀（和电磁阀配套）

- **速度**：水平排气节流；垂直提升才考虑进气节流。节流阀靠近缸，不要拧在阀岛排气口上指望细调每一缸。
- **压力**：总减压 0.4–0.6 MPa；压装/夹紧可分路再减压。顺序阀少用，能靠电气互锁就不要靠气压顺序。
- **真空**：发生器配 3/2 或专用真空阀，破坏用 2/2；不要拿普通 5/2 硬凑真空。

## 5. 和时序图的衔接

选阀之前，时序图已经决定了：

- 单电还是双电（要不要失电保持）
- 能不能并联（阀岛上相邻阀同时 ON 的峰值流量）
- 完成信号是磁性开关还是延时（延时阀不是首选）

先读 `09-控制工程/节拍与时序图.md`，再填阀表。

## 6. 反模式

1. 全机抄同一个 5/2 单电，垂直缸没有失电回缩或机械锁  
2. 5/3 中封当“刹车”用，不装保压阀  
3. 双电控两个线圈同时给电  
4. 阀岛装在电柜里，气管拖 3 米到机构  
5. 用总延时代替到位信号  
6. 无油缸却加油雾器  
7. 消声器堵了还怪气缸慢  
8. 阀岛不编号，电气 I/O 叫 Y1、机械图叫“阀”
