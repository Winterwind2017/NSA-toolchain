> 来源: 基恩士/欧姆龙/SMC 选型手册、现场调试经验

## 1. NPN vs PNP 完整对照

### 1.1 核心区别

| 特性 | NPN (漏型) | PNP (源型) |
|------|:---------:|:---------:|
| 输出导通 | OUT→GND (低电平) | OUT→VCC (高电平) |
| 负载接法 | 负载接 VCC→OUT | 负载接 OUT→GND |
| 典型 PLC | 三菱/欧姆龙(日系) | 西门子/施耐德(欧系) |
| 抗干扰 | 共地系统优 | 长距离传输优 |
| 三线颜色 | 棕=VCC, 蓝=GND, 黑=OUT | 棕=VCC, 蓝=GND, 黑=OUT |

### 1.2 接线图

```
NPN 接线:                    PNP 接线:
  VCC ──┬── 负载 ──┐          VCC ──┬── 传感器棕线
        │          │                │
        │    传感器  │          传感器 │
        │  棕──VCC  │          蓝──GND──┐
        │  蓝──GND  │          黑──OUT──┤
        │  黑──OUT──┘                │  负载
        │                           │
  GND ──┘                     GND ──┘
```

### 1.3 混用解决方案

```
NPN 传感器 → PNP PLC:  加中间继电器转换
PNP 传感器 → NPN PLC:  加中间继电器转换
禁止直接混接 → 可能烧毁 PLC 输入点！
```

## 3. 传感器调试检查清单

- [ ] NPN/PNP 与 PLC 输入模块匹配？
- [ ] 供电电压正确 (12V/24V)？
- [ ] 检测距离在规格范围内？
- [ ] 安装间距满足防串扰要求？
- [ ] 响应频率满足产线速度？
- [ ] 防护等级满足环境要求？
- [ ] 常开/常闭逻辑正确？
- [ ] 屏蔽线单端接地？

## 4. 常见故障排查

| 故障 | 可能原因 | 解决 |
|------|---------|------|
| 无信号 | 接线反/供电错/传感器坏 | 万用表测 OUT 线电压 |
| 误触发 | 背景干扰/粉尘/振动 | 换背景抑制型/加防护罩 |
| 信号抖动 | 检测距离临界/电磁干扰 | 调整距离/加屏蔽 |
| 响应慢 | 响应频率不够 | 换高速型号 |
| 检测不到 | 材质不匹配/距离超 | 换电容式/调距离 |
