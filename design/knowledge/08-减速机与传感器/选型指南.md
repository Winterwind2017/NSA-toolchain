# 减速机与传感器选型 — 非标自动化必备

> 来源: 恩坦斯特/哈默纳科/纳博特斯克选型手册、基恩士/欧姆龙传感器手册、非标设计经验
> 用途: 传动系统匹配、检测系统选型

## 1. 减速机选型

### 1.1 减速机类型对比

| 类型 | 传动比范围 | 背隙 | 效率 | 刚性 | 适用场景 |
|------|:---------:|:----:|:----:|:----:|---------|
| 行星减速机 | 3~100 | 1~10 arcmin | 95~97% | 高 | **通用精密传动（最常用）** |
| 谐波减速机 | 30~160 | ≈0 | 80~90% | 中 | 轻载精密/机器人腕部 |
| RV减速机 | 30~200 | 1~2 arcmin | 85~92% | **极高** | 重载机器人关节 |
| 蜗轮蜗杆 | 5~100 | 大 | 40~90% | 中 | 大减速比/自锁/垂直提升 |
| 斜齿轮减速机 | 3~200 | 5~15 arcmin | 94~97% | 高 | 通用传动 |

### 1.2 行星减速机选型公式

```
传动比:  i = n_motor / n_output

输出扭矩:  T_out = T_motor × i × η × K_A

η = 传动效率 (0.95~0.97)
K_A = 工况系数:
  平稳负载: 1.2~1.5
  中等冲击: 1.5~2.0
  重度冲击: 2.0~2.5

校核条件:
  T_rated ≥ T_out (持续)
  T_peak ≥ T_motor × i × η (峰值/启动)
  n_input ≤ n_max_allowed
```

### 1.3 背隙精度选择

| 应用场景 | 推荐背隙 | 说明 |
|---------|:-------:|------|
| 机器人关节/CNC | ≤ 3 arcmin | 零背隙/低背隙 |
| 自动化搬运/装配 | 3~10 arcmin | 性价比最优 |
| 输送线/风机 | 10~30 arcmin | 不追求精度 |

### 1.4 惯量折算

```
加减速机后负载惯量折算到电机轴:
  J_L' = J_L / i²

惯量比:  R = J_L' / J_M
推荐:  R ≤ 5 (伺服), R ≤ 10 (步进)
```

### 1.5 谐波 vs RV 选择

| 条件 | 谐波减速机 | RV减速机 |
|------|:---------:|:-------:|
| 负载 < 10kg | ✅ 首选 | — |
| 负载 > 10kg | — | ✅ 首选 |
| 空间极受限 | ✅ | — |
| 频繁冲击 | ⚠️ 安全系数 2.5~3 | ✅ 安全系数 1.5~2 |
| 高刚性需求 | — | ✅ |
| 零背隙 | ✅ | ✅ |

## 2. 传感器选型

### 2.1 传感器类型速查

| 类型 | 检测对象 | 检测距离 | 精度 | 响应速度 | 典型应用 |
|------|---------|:-------:|:----:|:-------:|---------|
| 光电-对射 | 任何不透明物 | 0.1~30m | 高 | 极快 | 有无检测/计数 |
| 光电-镜反射 | 任何物 | 0.1~10m | 高 | 快 | 有无检测 |
| 光电-漫反射 | 任何物 | 10~500mm | 中 | 快 | 紧凑空间检测 |
| 光电-背景抑制 | 任何物 | 10~300mm | 高 | 快 | 消除背景干扰 |
| 接近-电感 | 金属 | 1~30mm | 高 | 快 | 金属到位检测 |
| 接近-电容 | 金属+非金属 | 1~20mm | 中 | 中 | 液位/塑料检测 |
| 光纤 | 微小物 | 1~500mm | 极高 | 极快 | 小零件精密检测 |
| 激光位移 | 任何物 | 10~2000mm | μm级 | 快 | 尺寸/厚度测量 |
| 光栅尺 | — | — | nm级 | 快 | 闭环定位 |
| 视觉相机 | 复杂特征 | 视FOV | 像素级 | 中 | OCR/缺陷/引导 |
| 力传感器 | 力/力矩 | — | 0.1%FS | 快 | 压装力监控 |
| 安全光幕 | 人体 | — | — | <20ms | 安全防护 |

### 2.2 选型决策树

```
检测什么？
├── 有无/到位 → 光电(对射/反射) 或 接近开关
│   ├── 金属 → 电感式接近 (成本低/可靠)
│   ├── 非金属 → 光电 或 电容式接近
│   └── 高速计数 → 对射光电 (响应频率高)
├── 精确位置 → 位移传感器
│   ├── μm级 → 光栅尺/激光位移
│   └── mm级 → 磁致伸缩/拉绳编码器
├── 力/压力 → 力传感器/压力传感器
├── 复杂特征 → 视觉相机
│   ├── 字符识别 → OCR相机
│   ├── 缺陷检测 → 面阵相机+算法
│   └── 定位引导 → 面阵相机+标定
└── 安全防护 → 安全光幕/安全门开关
```

### 2.3 电气接口匹配

| 输出类型 | 说明 | PLC 匹配 |
|---------|------|---------|
| NPN 开集 | 低电平有效 | NPN 输入模块 |
| PNP 开集 | 高电平有效 | PNP 输入模块 |
| 模拟量 4~20mA | 连续信号 | 模拟量输入模块 |
| 模拟量 0~10V | 连续信号 | 模拟量输入模块 |
| IO-Link | 数字通信 | IO-Link 主站 |

**注意**: NPN/PNP 必须与 PLC 输入模块匹配，否则信号反相！

### 2.4 环境防护

| 环境 | 推荐防护等级 | 额外措施 |
|------|:----------:|---------|
| 一般车间 | IP65 | — |
| 油污/水溅 | IP67 | 不锈钢外壳 |
| 食品/清洗 | IP69K | 全密封 |
| 粉尘 | IP65+ | 对射型优先 |
| 高温 | 查温度规格 | 光纤分离型 |

## 3. 气动系统设计

### 3.1 系统组成

设备侧元件种类见 `05-标准件选型/气动元件选型.md`，用 `pneumatic.recommend_actuator`。厂务气源到执行器：

```
空压机 → 储气罐 → 干燥机 → 三联件(过滤+减压+油雾) → 电磁阀 → 气缸
                                                          ↑
                                                    PLC 控制信号
```

### 3.2 电磁阀选型

详细 9 步流程见 `08-减速机与传感器/电磁阀选型.md`，计算用 `pneumatic.valve_select`。

| 阀型 | 通路 | 适用气缸 | 典型应用 |
|------|:----:|---------|---------|
| 2/2 通 | 开/关 | — | 气源总开关/吹气 |
| 3/2 通 | 单作用 | 弹簧复位气缸 | 夹紧/吹气/真空发生 |
| 5/2 通 | 双作用 | 双作用气缸 | **最常用** |
| 5/3 通中封 | 双作用+中停 | 双作用气缸 | 中间定位，不能当刹车 |
| 5/3 通中排 | 双作用+自由 | 双作用气缸 | 需手动调整 |

### 3.3 气管规格

| 气管外径 (mm) | 适用缸径 | 流量能力 |
|:------------:|:-------:|---------|
| Φ4 | ≤ 16mm | 小流量 |
| Φ6 | 16~32mm | 中流量 |
| Φ8 | 32~63mm | 中大流量 |
| Φ10 | 63~100mm | 大流量 |
| Φ12 | ≥ 100mm | 超大流量 |

### 3.4 气动设计避坑

| 问题 | 原因 | 解决 |
|------|------|------|
| 气缸爬行 | 排气节流锁太紧/背压过高 | 回松 1/4 圈 |
| 动作慢 | 阀离缸太远/管径太小 | 阀装缸旁/放大管径 |
| 漏气 | 气管端面不垂直/未插到底 | 切平+插到底 |
| 消声器背压 | 消声器通径太小 | 选比排气口大一号 |
| 无油缸加润滑油 | 洗掉原有润滑脂 | 禁止混用 |
| 气锤现象 | 多缸并联压力不均 | 串联节流阀/背压阀 |
