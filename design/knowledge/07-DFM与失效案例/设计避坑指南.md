# DFM 与失效案例 — 常见设计错误 / 加工约束 / 装配陷阱

> 来源: 非标自动化行业经验总结、机械设计论坛、失效分析报告
> 用途: 设计审查、避坑指南

---

## 1. 机加工 DFM 约束

| 约束 | 规则 | 违反后果 |
|------|------|---------|
| 内尖角 | 所有内角 R ≥ 3mm (铣刀半径) | 无法加工/应力集中 |
| 深腔 | 长径比 ≤ 3 (普通铣刀) | 需特制刀具/颤振 |
| 薄壁 | 壁厚 ≥ 2mm (钢) / ≥ 1.5mm (铝) | 加工变形 |
| 螺纹孔 | 有效深度 ≥ 1.5d, 底孔深 ≥ 螺纹深+2p | 螺纹强度不足 |
| 沉头孔 | 沉头角 90°, 深度 = 螺钉头厚+0.5 | 螺钉头突出 |
| 退刀槽 | 磨削面两端留退刀槽 | 无法磨到根部 |
| 孔间距 | 孔边距 ≥ 1.5d, 孔间距 ≥ 3d | 孔壁破裂 |

## 2. 钣金 DFM 约束

| 约束 | 规则 | 违反后果 |
|------|------|---------|
| 折弯半径 | R ≥ 板厚 t | 开裂 |
| 孔距折弯边 | ≥ 2t + R | 孔变形 |
| 折弯边最小高度 | ≥ 2t + R | 无法折弯 |
| 切口宽度 | ≥ t | 模具强度不足 |
| 百叶窗 | 高度 ≤ 材料厚度×3 | 拉伸破裂 |

## 3. 焊接 DFM 约束

| 约束 | 规则 | 违反后果 |
|------|------|---------|
| 焊缝可达性 | 焊枪/焊条能到达 | 无法焊接 |
| 薄厚突变 | 过渡斜度 ≤ 1:3 | 淬裂/变形 |
| 对称焊接 | 对称布置焊缝 | 焊接变形 |
| 封闭焊缝 | 避免完全封闭 | 应力集中/气孔 |
| 焊后加工 | 预留加工余量 | 变形后无法加工 |

## 4. 装配 DFA 约束

| 约束 | 规则 | 违反后果 |
|------|------|---------|
| 装配方向 | 尽量从上往下 (Z 方向) | 翻转困难 |
| 定位特征 | 每个零件至少 2 个定位面/销 | 装配位置不确定 |
| 防呆设计 | 对称件加不对称特征 | 装反 |
| 紧固件统一 | 同规格尽量统一 | 换工具频繁 |
| 调整机构 | 预留调整垫片/偏心销 | 累积误差无法补偿 |
| 维修可达 | 易损件可从外部更换 | 需拆整机 |

## 5. 非标设计十大常见错误

| # | 错误 | 正确做法 |
|---|------|---------|
| 1 | 气缸选型不考虑负载率 | 动载 β ≤ 0.5, 静载 β ≤ 0.7 |
| 2 | 丝杆不校核临界转速 | n_max ≤ 0.8·n_cr |
| 3 | 导轨安装面不标平面度 | 标 0.02/1000mm |
| 4 | 悬臂结构不校核挠度 | δ ≤ L/500 |
| 5 | 螺栓不标防松措施 | 弹簧垫圈/螺纹胶/防松螺母 |
| 6 | 运动件不考虑润滑 | 设计油槽/油嘴/润滑孔 |
| 7 | 传感器支架不可调 | 设计腰形孔/微调螺钉 |
| 8 | 线缆不考虑弯曲半径 | 拖链内 R ≥ 线缆外径×6 |
| 9 | 安全防护缺失 | 运动区加光栅/安全门/急停 |
| 10 | 操作高度不合理 | 操作面 800~900mm |

## 6. 失效模式速查

| 失效模式 | 原因 | 预防措施 |
|---------|------|---------|
| 疲劳断裂 | 交变应力+应力集中 | 加圆角、降应力、选高疲劳强度材料 |
| 磨损 | 滑动摩擦无润滑 | 加润滑、选耐磨材料(POM/铜)、表面处理 |
| 压溃 | 局部接触应力过大 | 增大接触面积、加垫片 |
| 失稳 | 细长杆受压 | 校核欧拉临界力、加中间支撑 |
| 蠕变 | 高温+持续载荷 | 降温度、选耐热材料 |
| 腐蚀 | 异种金属接触/潮湿 | 隔离、选不锈钢、表面处理 |
| 松动 | 振动+无防松 | 防松螺母/螺纹胶/弹簧垫圈 |
| 变形 | 焊接残余应力 | 焊后退火、对称焊接 |

## 7. 设计审查清单

### 功能检查
- [ ] 所有运动件行程是否足够？
- [ ] 工件取放/定位/夹紧是否可靠？
- [ ] 节拍是否满足？
- [ ] 传感器能否可靠检测？

### 强度检查
- [ ] 承载件是否校核 von Mises？
- [ ] 交变件是否做疲劳分析？
- [ ] 细长件是否校核压杆稳定？

### DFM 检查
- [ ] 内角是否 ≥ R3？
- [ ] 深腔长径比是否 ≤ 3？
- [ ] 螺纹孔深度是否足够？

### DFA 检查
- [ ] 装配方向是否合理？
- [ ] 是否有防呆设计？
- [ ] 易损件是否可外部更换？

### 安全检查
- [ ] 运动区是否有防护？
- [ ] 是否有急停按钮？
- [ ] 操作高度是否合理？
