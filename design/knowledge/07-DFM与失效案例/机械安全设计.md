# 机械安全设计 — 非标自动化设备安全规范

> 来源: GB/T 15706 机械安全、GB 5226.1 电气安全、ISO 13849 安全相关控制系统、非标实务经验
> 用途: 非标设备安全设计、风险评估、防护装置设计

---

## 1. 安全设计基本原则

### 1.1 安全设计三步法

```
第一步: 本质安全设计（消除危险）
  → 优化结构，避免危险区域，降低能量

第二步: 安全防护装置（隔离危险）
  → 防护罩、安全门、光幕、双手按钮

第三步: 使用信息（提醒注意）
  → 警示标识、操作手册、培训
```

**优先级**: 本质安全 > 防护装置 > 使用信息

### 1.2 风险评估流程

```
确定设备范围 → 识别危险 → 估算风险 → 风险评价 → 采取措施 → 验证有效性
```

### 1.3 风险等级评估

| 严重程度 | 频率 | 避免可能性 | 风险等级 |
|---------|------|-----------|---------|
| 致命 | 频繁 | 不可能 | 极高 |
| 严重 | 偶尔 | 可能 | 高 |
| 轻微 | 很少 | 容易 | 中 |
| 可忽略 | 极少 | 很容易 | 低 |

## 2. 机械防护设计

### 2.1 防护罩设计

| 防护类型 | 适用场景 | 设计要求 |
|---------|---------|---------|
| 固定防护罩 | 不需要经常进入的区域 | 工具才能拆卸，无锐边 |
| 联锁防护罩 | 需要经常进入的危险区 | 打开即停机，关闭才能启动 |
| 可调防护罩 | 不同工件需要调整 | 调整后固定，覆盖危险区 |
| 自关闭防护罩 | 工件进出频繁 | 自动关闭，有配重/弹簧 |

### 2.2 安全距离计算

```
最小安全距离 = K × T + C

其中:
  K = 接近速度 (mm/s)，一般 2000 mm/s
  T = 系统响应时间 (s) = 传感器响应 + 控制器响应 + 制动器响应
  C = 附加距离 (mm)，根据侵入深度

示例:
  光幕响应 10ms + PLC 10ms + 制动 100ms = 120ms
  安全距离 = 2000 × 0.12 + 850 = 1090 mm
```

### 2.3 防护装置安全要求

- 防护罩本身不能成为危险源（无锐边、无尖角）
- 联锁装置必须可靠，不能被轻易旁路
- 防护罩应能承受预期的外力和振动
- 透明防护罩用聚碳酸酯（PC），不用亚克力（易碎）
- 旋转部件防护罩应能容纳破裂的零件

## 3. 安全控制装置

### 3.1 安全装置类型

| 装置 | 功能 | 适用场景 | 安全等级 |
|------|------|---------|---------|
| 急停按钮 | 紧急停止所有运动 | 所有设备 | 最高 |
| 安全光幕 | 检测人员侵入 | 上下料工位 | 高 |
| 安全门开关 | 检测门是否关闭 | 防护罩门 | 高 |
| 双手按钮 | 双手同时操作才启动 | 冲压、压装 | 高 |
| 安全地毯 | 检测人员站立 | 危险区域地面 | 中 |
| 激光扫描仪 | 区域防护 | 机器人工作区 | 高 |
| 安全继电器 | 监控安全回路 | 所有安全回路 | - |

### 3.2 急停按钮设计要求

- 红色蘑菇头，黄色背景
- 一按即停，自锁，手动旋转复位
- 每个操作工位至少一个
- 设备两端各一个（长设备）
- 急停后必须手动复位才能重启
- 急停回路独立于正常控制回路
- 急停按钮不能作为正常停止使用

### 3.3 安全光幕选型

```
光幕高度 ≥ 危险区高度 + 200mm（上下各100mm）
光轴间距:
  手指防护: 14mm
  手掌防护: 30mm
  身体防护: 40~90mm

安全距离按 3.2 公式计算
```

### 3.4 双手按钮要求

- 两个按钮间距 ≥ 260mm（防止单手操作）
- 两个按钮必须同时按下（时间差 < 0.5s）
- 松开任一按钮即停止
- 必须双手都松开后才能再次启动
- 按钮高度在肘部附近，避免疲劳

## 4. 电气安全

### 4.1 电气安全基本要求

- 控制柜防护等级 ≥ IP54（车间环境）
- 所有金属部件必须接地（保护接地 PE）
- 接地电阻 ≤ 0.1Ω
- 控制电路与动力电路隔离
- 柜门打开自动断电（门开关）
- 柜内有照明和插座
- 线槽布线，强弱电分开

### 4.2 安全电路设计

- 安全回路用双通道（冗余设计）
- 安全继电器监控回路状态
- 单通道故障不导致安全功能丧失
- 定期测试安全回路（测试脉冲）
- 急停、光幕、安全门接入安全继电器

### 4.3 动力电路保护

| 保护类型 | 功能 | 选型 |
|---------|------|------|
| 断路器 | 过载/短路保护 | 按电机额定电流 1.25 倍 |
| 接触器 | 电机启停控制 | 按电机功率选型 |
| 热继电器 | 电机过载保护 | 按电机额定电流整定 |
| 滤波器 | 抑制电磁干扰 | 按系统功率选型 |
| 浪涌保护器 | 防雷/浪涌 | 进线处安装 |

## 5. 气动安全

### 5.1 气动安全要求

- 气源处理三联件（过滤+减压+油雾）
- 系统最高压力 ≤ 0.7MPa
- 蓄能器必须有安全泄压阀
- 气缸有伸出/缩回两端检测
- 垂直气缸必须有断气保护（锁紧/平衡）
- 真空吸盘有真空压力检测
- 管路用快插接头，有防脱措施

### 5.2 气缸安全设计

| 风险 | 对策 |
|------|------|
| 气缸飞出 | 两端加限位/缓冲 |
| 断气下落 | 垂直缸用锁紧气缸或平衡阀 |
| 速度过快 | 加节流阀，限速 |
| 夹紧力过大 | 调压阀限压，力传感器监控 |
| 误动作 | 加位置检测，逻辑互锁 |

## 6. 运动安全

### 6.1 运动部件安全

- 直线运动两端有硬限位和软限位
- 旋转部件有防护罩，无裸露
- 同步带/链条有防护罩
- 运动路径无干涉（3D检查）
- 最大速度限制（软件+硬件）
- 加速度限制（避免冲击）
- 原点回归有碰撞检测

### 6.2 伺服系统安全

- 伺服驱动器有过流、过压、过载保护
- 编码器反馈监控，断线报警
- 位置偏差过大报警（防止丢步）
- 紧急停止时动态制动
- 上电时伺服 OFF，手动使能
- 手动模式限速（≤ 100mm/s）

### 6.3 机器人安全

- 机器人工作区有安全围栏
- 围栏门有安全联锁
- 示教模式限速（≤ 250mm/s）
- 机器人有碰撞检测功能
- 外围设备与机器人通讯互锁
- 急停按钮在示教器和操作盒上

## 7. 人机工程安全

### 7.1 操作工位设计

| 项目 | 要求 |
|------|------|
| 操作高度 | 900~1100mm（站立），700~800mm（坐姿） |
| 操作距离 | 手可达范围 ≤ 500mm |
| 视野 | 工件和操作区清晰可见 |
| 照明 | ≥ 300 lux（一般），≥ 500 lux（精密） |
| 噪音 | ≤ 75 dB(A) |
| 温度 | 18~28°C |
| 负重 | 单人 ≤ 15kg，超过用助力装置 |

### 7.2 维护安全

- 维护空间 ≥ 600mm（正面），≥ 400mm（侧面）
- 易损件从外部可更换
- 有维护平台/梯子（高处设备）
- 锁定/挂牌（LOTO）程序
- 维护时能量隔离（电、气、液压）
- 有明确的维护警示标识

## 8. 安全标识

### 8.1 安全色

| 颜色 | 含义 | 用途 |
|------|------|------|
| 红色 | 禁止/危险 | 急停、禁止标识、消防 |
| 黄色 | 警告 | 注意安全、当心机械 |
| 蓝色 | 指令 | 必须佩戴防护用品 |
| 绿色 | 安全 | 安全出口、急救、启动 |

### 8.2 必备安全标识

- 设备名称/编号牌
- 急停按钮标识
- 当心机械伤人
- 当心触电
- 必须接地
- 非专业人员禁止打开
- 安全操作规程
- 额定参数（电压、气压、功率）

## 9. 安全设计检查清单

### 9.1 机械安全

- [ ] 所有运动部件有防护罩
- [ ] 防护罩联锁可靠
- [ ] 安全距离符合要求
- [ ] 无锐边、尖角、凸出物
- [ ] 限位装置可靠（软+硬）
- [ ] 旋转部件无裸露
- [ ] 维护空间充足

### 9.2 控制安全

- [ ] 急停按钮数量足够，位置合理
- [ ] 急停回路独立，双通道
- [ ] 安全光幕/安全门配置正确
- [ ] 安全继电器监控所有安全回路
- [ ] 双手按钮符合要求（间距、同步）
- [ ] 上电时伺服 OFF
- [ ] 手动模式限速

### 9.3 电气安全

- [ ] 控制柜防护等级达标
- [ ] 所有金属部件接地
- [ ] 柜门开关断电
- [ ] 断路器/热继电器配置正确
- [ ] 强弱电分开布线
- [ ] 有浪涌保护

### 9.4 气动安全

- [ ] 气源处理三联件
- [ ] 系统压力限制
- [ ] 垂直气缸断气保护
- [ ] 真空压力检测
- [ ] 气缸两端缓冲/限位

### 9.5 人机工程

- [ ] 操作高度合理
- [ ] 照明充足
- [ ] 噪音达标
- [ ] 负重有助力
- [ ] 维护可达性好

### 9.6 安全标识

- [ ] 安全色使用正确
- [ ] 必备标识齐全
- [ ] 操作规程张贴
- [ ] 额定参数标识
