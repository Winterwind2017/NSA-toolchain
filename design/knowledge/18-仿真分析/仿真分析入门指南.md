# 仿真分析入门指南

## 一、常用仿真类型

| 类型 | 目的 | 常用软件 |
|------|------|----------|
| 静力分析 | 强度、变形校核 | SolidWorks Simulation, ANSYS |
| 模态分析 | 固有频率、振型 | SolidWorks Simulation, ANSYS |
| 谐响应分析 | 共振校核 | ANSYS, ABAQUS |
| 屈曲分析 | 压杆稳定 | ANSYS, ABAQUS |
| 热分析 | 温度场、热变形 | ANSYS, COMSOL |
| 运动仿真 | 机构运动、干涉 | SolidWorks Motion, ADAMS |

## 二、静力分析流程

### 步骤 1: 前处理

1. **简化模型**
   - 去掉小特征 (倒角、小孔)
   - 去掉不重要的细节
   - 对称结构取一半

2. **定义材料**
   - 弹性模量 E
   - 泊松比 μ
   - 密度 ρ
   - 屈服强度 σ_s

3. **划分网格**
   - 单元类型: 实体单元 (Solid)
   - 单元尺寸: 重要区域细化
   - 网格质量检查

### 步骤 2: 施加载荷与约束

1. **约束**
   - 固定约束 (Fixed)
   - 位移约束
   - 对称约束

2. **载荷**
   - 力载荷
   - 压力载荷
   - 重力载荷
   - 轴承载荷

### 步骤 3: 求解与后处理

1. **求解**
   - 检查单位
   - 检查约束是否充分
   - 运行求解

2. **结果分析**
   - 应力分布 (von Mises)
   - 变形分布
   - 安全系数分布
   - 危险点识别

## 三、结果判断标准

### 应力判断

```
安全系数 = 屈服强度 / 最大应力

一般结构: n ≥ 1.5
重要结构: n ≥ 2.0
疲劳结构: n ≥ 2.5
```

### 变形判断

```
许用变形:
- 导轨安装面: L/1000
- 一般机架: L/500
- 非重要结构: L/200
```

## 四、模态分析入门

### 什么是模态分析

- 计算结构的固有频率和振型
- 避免共振
- 评估动态特性

### 关键参数

```
固有频率 f_n = (1/2π) × √(k/m)

k: 刚度
m: 质量
```

### 共振规避

```
工作频率应避开固有频率的 ±20% 范围
激励频率 < 0.8 × f_n 或 > 1.2 × f_n
```

## 五、运动仿真入门

### 应用场景

- 机构运动干涉检查
- 运动轨迹验证
- 速度/加速度分析
- 驱动力矩计算

### 仿真步骤

1. 添加马达/驱动力
2. 添加弹簧/阻尼
3. 添加接触/碰撞
4. 运行仿真
5. 分析结果

## 六、常用软件对比

| 软件 | 优点 | 缺点 | 应用 |
|------|------|------|------|
| SolidWorks Simulation | 易学，集成好 | 功能有限 | 日常设计校核 |
| ANSYS Workbench | 功能强大 | 学习曲线陡 | 复杂分析 |
| ABAQUS | 非线性强 | 价格贵 | 高端研究 |
| COMSOL | 多物理场 | 价格贵 | 耦合分析 |

## 七、常见问题

### 网格问题

- 网格太粗: 结果不准确
- 网格太细: 计算慢
- 建议: 先粗网格试算，再细化

### 应力集中

- 尖角处应力集中
- 建议: 加圆角，细化网格

### 单位错误

- 最常见错误
- 建议: 统一单位制 (mm, N, MPa)
