# 非标自动化项目成本估算

> 非标自动化设备项目成本构成、估算方法、报价模板。
> 参考行业经验：3C/锂电/光伏/汽车零部件行业非标项目报价惯例。

---

## 一、项目成本构成

### 1.1 成本分类总览

| 大类 | 占比参考 | 说明 |
|------|---------|------|
| **机械设计** | 15~25% | 设计工时、图纸、BOM |
| **电气设计** | 5~10% | 电气原理图、PLC程序、HMI |
| **标准件采购** | 25~35% | 电机/气缸/导轨/PLC/传感器等 |
| **机加工件** | 10~20% | 钣金/铝件/机加/3D打印 |
| **装配调试** | 10~15% | 机械装配、电气接线、调试 |
| **包装运输** | 2~5% | 木箱/运输/保险 |
| **项目管理** | 5~8% | 项目经理/进度管理 |
| **利润+税金** | 15~25% | 毛利、增值税、管理费 |

### 1.2 典型项目报价结构

```
设备总价 = 直接成本 + 间接成本 + 利润 + 税金
```

## 三、机加工件成本估算

### 3.1 加工方式成本参考

| 加工方式 | 计价方式 | 价格区间 |
|---------|---------|---------|
| **铝板加工** | 按重量/按小时 | 80~150元/kg |
| | 加工小时 | 80~150元/小时 |
| **钣金加工** | 按展开面积 | 200~400元/㎡ |
| | 按重量 | 15~30元/kg |
| **3D打印** | 按重量 | 2~5元/g (PLA/ABS) |
| | 按重量 | 5~15元/g (尼龙/金属) |
| **线切割** | 按面积 | 0.01~0.02元/mm² |
| **激光切割** | 按长度 | 1~5元/米 (碳钢) |
| **CNC加工** | 按小时 | 80~200元/小时 |

### 3.2 常用材料价格

| 材料 | 价格 (元/kg) | 密度 (g/cm³) |
|------|-------------|-------------|
| 6061铝板 | 25~35 | 2.7 |
| 45#钢板 | 8~15 | 7.85 |
| 不锈钢304 | 25~40 | 7.93 |
| 亚克力板 | 20~40 | 1.18 |
| POM棒 | 30~50 | 1.41 |
| 铝型材 (欧标) | 20~50元/米 | - |

### 3.3 加工费估算公式

```
机加工件成本 = 材料费 + 加工费 + 表面处理费

材料费 = 体积 × 密度 × 材料单价
加工费 = 加工时间 × 小时费率
表面处理费 = 面积 × 单位面积价格 (阳极氧化/喷塑/电镀)
```

## 五、报价模板

### 5.1 标准报价单结构

```
一、设备概述
   设备名称、用途、产能、技术参数

二、设备配置清单
   1. 机械部分
      - 标准件清单 (名称/规格/数量/单价/总价)
      - 机加工件清单 (名称/材料/数量/单价/总价)
   2. 电气部分
      - 电气元件清单
   3. 软件部分
      - PLC程序/HMI/视觉

三、项目周期
   设计周期 / 采购周期 / 装配周期 / 调试周期 / 总周期

四、商务条款
   付款方式 / 交货地点 / 验收标准 / 质保期
```

## 六、报价注意事项

### 6.1 常见报价陷阱

1. **漏项**
   - 未考虑气管/线缆/接头/标准紧固件
   - 未考虑包装运输费用
   - 未考虑现场调试差旅费用

2. **选型偏低**
   - 标准件按最低价选型，实际需要更高规格
   - 未考虑备品备件成本
   - 未考虑售后维护成本

3. **工时估算不足**
   - 调试时间通常是设计时间的1.5~2倍
   - 现场调试时间容易低估
   - 未考虑客户需求变更的时间成本

### 6.2 报价策略

| 客户类型 | 报价策略 | 利润率 |
|---------|---------|--------|
| 新客户 | 适当低价，建立信任 | 10~15% |
| 老客户 | 稳定价格，保证质量 | 15~20% |
| 急单 | 加急费用，优先排产 | 20~30% |
| 竞品项目 | 有竞争力的价格 | 10~15% |
| 长期合作 | 合理利润，长期共赢 | 15~20% |

## 七、成本控制要点

### 7.1 设计阶段成本控制

1. **标准化设计**
   - 尽量使用标准件，减少非标件
   - 建立标准图库，复用成熟模块
   - 优先选用常用规格，减少特殊规格

2. **材料选择**
   - 满足性能要求前提下，选用性价比高的材料
   - 减少材料种类，方便采购和库存
   - 考虑材料利用率，减少废料

3. **加工工艺**
   - 尽量采用常规加工工艺，减少特殊工艺
   - 设计时考虑加工便利性
   - 减少复杂曲面和高精度要求

### 7.2 采购阶段成本控制

1. **供应商管理**
   - 建立合格供应商名录
   - 定期比价，争取优惠价格
   - 大批量采购争取折扣

2. **交期管理**
   - 长交期物料提前下单
   - 避免加急费用
   - 合理安排库存
