## 1. 电气原理图规范

### 1.1 图层规范 (CAD/EPLAN)

| 图层名 | 颜色 | 线型 | 用途 |
|--------|:----:|:----:|------|
| POWER | 红 | Continuous | 主电路 (380V/220V) |
| CONTROL | 蓝 | Continuous | 控制回路 (24V) |
| TERMINAL | 绿 | Continuous | 端子接线 |
| TEXT | 白 | Continuous | 文字标注 |
| SAFETY | 黄 | Continuous | 安全回路 |
| COMM | 青 | Continuous | 通信线 |

### 1.2 原理图页面结构

```
页1:  封面/目录
页2:  电源系统 (220VAC→24VDC 分配)
页3:  主电路 (断路器/接触器/电机)
页4:  PLC 电源+CPU
页5:  PLC DI 接线 (传感器输入)
页6:  PLC DO 接线 (电磁阀/继电器输出)
页7:  PLC AI/AO 接线 (模拟量)
页8:  伺服驱动器接线
页9:  安全回路 (急停/安全门/光幕)
页10: 端子排图
页11: 柜体布置图
页12: 线缆清单
```

### 1.3 关键设计规则

```
1. 不同电压等级严禁同一图层
2. 急停回路必须硬接线, 不经 PLC
3. 模拟量屏蔽层单端接地 (PLC 侧)
4. 备用端子预留 10~15%
5. 每个端子排标注功能定义
6. 线号与现场标签一致
7. 变频器与信号线物理隔离 ≥ 100mm
```

## 2. 安全回路设计 (ISO 13849)

### 2.1 安全等级选择

| 风险等级 | PL 等级 | 类别 | 典型应用 |
|:-------:|:------:|:----:|---------|
| 低 | PL a/b | Cat.1 | 低风险防护 |
| 中 | PL c | Cat.2 | 安全门联锁 |
| 高 | PL d | Cat.3 | 安全光幕/双手控制 |
| 极高 | PL e | Cat.4 | 冲压/机器人围栏 |

### 2.2 双通道冗余接线

```
急停回路 (双通道):
  急停按钮 S1
    ├── 通道A: NC触点1 → 安全继电器 S11-S12
    └── 通道B: NC触点2 → 安全继电器 S21-S22

安全继电器输出:
    ├── 13/14 (安全常开) → 主接触器线圈
    ├── 23/24 (安全常开) → 伺服 STO
    └── 21/22 (辅助常闭) → PLC 反馈 (监控触点粘连)

故障保护:
  接触器主触点粘连 → 21/22 断开 → 安全继电器无法复位
```

## 3. 抗干扰设计

| 干扰源 | 措施 |
|--------|------|
| 变频器 | 信号线双绞屏蔽, 载波频率降至 4kHz |
| 电机启停 | 加 RC 吸收器/压敏电阻 |
| 电磁阀 | 加续流二极管 |
| 接地不良 | PLC 柜单独接地 ≥ 4mm², 接地电阻 ≤ 0.1Ω |
| 电源波动 | 加隔离变压器/UPS |
| 传感器误触发 | 光电加隔离变压器, 屏蔽层单端接地 |
