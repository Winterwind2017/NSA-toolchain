### 1.3 尺寸标注原则

```
        坡口角度 α
        根部间隙 b
          ↓  ↓
    h  ┌──────┐  l    n×
       │ 符号 │
  ─────┤      ├─────
       │      │
  - - -┤      ├─────  (虚线=非箭头侧)

h = 焊脚尺寸/坡口深度 (标在左侧)
l = 焊缝长度 (标在右侧)
n = 相同焊缝数量 (标在尾部)
α = 坡口角度 (标在上/下侧)
b = 根部间隙 (标在上/下侧)
```

## 2. 装配图规范

### 2.1 装配图必须包含

```
1. 一组视图 — 表达装配关系和工作原理
2. 必要尺寸 — 性能/装配/安装/外形尺寸
3. 技术要求 — 装配/调试/检验要求
4. 零件序号 — 按顺时针/逆时针排列
5. 明细栏 — 标题栏上方, 自下而上填写
6. 标题栏 — 右下角
```

### 2.2 装配图尺寸分类

| 类别 | 说明 | 示例 |
|------|------|------|
| 性能尺寸 | 反映设备性能 | 行程500mm, 力2000N |
| 装配尺寸 | 配合/相对位置 | φ30H7/k6, 间距100±0.1 |
| 安装尺寸 | 与外部连接 | 地脚孔距400×300 |
| 外形尺寸 | 总长×总宽×总高 | 1200×800×1500 |

**填写规则**: 自下而上, 序号与零件序号对应, 标准件写国标号

## 3. 图纸审核清单

### 3.1 零件图审核

- [ ] 视图完整, 无遗漏特征
- [ ] 尺寸完整, 无封闭尺寸链
- [ ] 公差合理, 配合正确
- [ ] 形位公差标注完整
- [ ] 表面粗糙度标注完整
- [ ] 材料牌号+状态正确
- [ ] 热处理要求明确
- [ ] 表面处理要求明确
- [ ] 技术要求完整
- [ ] 标题栏信息完整
- [ ] 图号唯一, 版本正确

### 3.2 装配图审核

- [ ] 所有零件有序号
- [ ] 明细栏与序号对应
- [ ] 配合尺寸标注完整
- [ ] 外形尺寸/安装尺寸标注
- [ ] 技术要求含装配/调试要求
- [ ] 干涉检查通过
- [ ] 运动件行程标注
- [ ] 标准件型号正确
