# 工程图规范 / 电气布线 / 安全标准

> 来源: GB/T 4457~4460、GB/T 131、GB 5226.1、非标设计经验
> 用途: 出图规范、电气设计、安全合规

---

## 1. 工程图规范 (GB)

### 1.1 图纸幅面

| 幅面 | 尺寸 (mm) | 适用 |
|:----:|:---------:|------|
| A0 | 841×1189 | 总装图 |
| A1 | 594×841 | 部件图 |
| A2 | 420×594 | 零件图(大) |
| A3 | 297×420 | **零件图(最常用)** |
| A4 | 210×297 | 小零件/表格 |

### 1.2 标题栏内容

```
必须包含:
  - 图号 / 名称 / 材料 / 重量 / 比例
  - 设计 / 审核 / 批准 / 日期
  - 单位名称 / 阶段标记
  - 共 X 张 第 X 张
```

### 1.3 技术要求模板

```
通用技术要求:
1. 未注公差按 GB/T 1804-m
2. 未注圆角 R2~R3
3. 未注倒角 C0.5~C1
4. 去除毛刺、锐边倒钝
5. 表面发黑/镀锌/阳极氧化 (按材料)
6. 热处理: 调质 HRC 28~32 (如需)
7. 焊接件焊后去应力退火
8. 装配后运动灵活、无卡滞
```

### 1.4 视图选择原则

```
主视图: 反映零件主要形状特征和工作位置
俯视图: 主视图正下方
左视图: 主视图正右方
剖视图: 内部结构复杂时
局部放大: 细小特征 (比例 2:1, 5:1)
```

## 2. 电气布线

### 2.1 线缆选型

| 用途 | 线缆类型 | 截面积 | 颜色 |
|------|---------|:-----:|:----:|
| 主电源 | RVV/BVR | 1.5~4 mm² | 棕/蓝/黄绿 |
| 伺服动力 | 屏蔽电缆 | 1.5~6 mm² | 按厂家 |
| 伺服编码器 | 双绞屏蔽 | 0.2~0.5 mm² | 按厂家 |
| 传感器信号 | 屏蔽线 | 0.2~0.5 mm² | 按信号 |
| 电磁阀 | RVV | 0.5~1.0 mm² | 按PLC |
| 接地 | BVR | ≥ 2.5 mm² | 黄绿 |

### 2.2 拖链选型

```
拖链内径 ≥ 线缆外径 × 1.2
弯曲半径 R ≥ 线缆外径 × 6 (推荐 × 8~10)
填充率 ≤ 70% (留散热空间)
分隔片: 动力线与信号线分开
```

### 2.3 电气柜布局

```
从上到下:
  1. 开关电源 / 断路器
  2. 伺服驱动器 / 变频器
  3. PLC / I/O 模块
  4. 继电器 / 端子排
  5. 线槽 (强弱电分开)

间距:
  驱动器间 ≥ 50mm (散热)
  强弱电线槽间距 ≥ 100mm
```

## 3. 安全标准

### 3.1 机械安全 (GB/T 15706 / ISO 12100)

| 措施 | 要求 |
|------|------|
| 急停按钮 | 每个操作位 ≥ 1 个，红色蘑菇头 |
| 安全门 | 运动区必须封闭，带安全联锁 |
| 安全光幕 | 人员可能进入的危险区 |
| 防护罩 | 旋转/往复运动件 |
| 安全色 | 红=停止/危险，黄=警告，绿=安全，蓝=指令 |

### 3.2 电气安全 (GB 5226.1 / IEC 60204-1)

| 要求 | 标准 |
|------|------|
| 接地电阻 | ≤ 0.1Ω |
| 绝缘电阻 | ≥ 1MΩ |
| 急停回路 | 硬接线，不经过 PLC |
| 安全回路 | 双通道冗余 (Category 3/4) |
| 防护等级 | 电气柜 ≥ IP54 |

### 3.3 安全等级

| 等级 | 说明 | 典型应用 |
|:----:|------|---------|
| PL a/b | 低风险 | 一般防护 |
| PL c | 中风险 | 安全门联锁 |
| PL d | 高风险 | 安全光幕 |
| PL e | 极高风险 | 双手控制/冗余 |

## 4. 人机工程

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 操作高度 | 800~900mm | 站立操作 |
| 显示屏高度 | 视线水平 ±15° | 避免低头/仰头 |
| 按钮间距 | ≥ 25mm | 防误触 |
| 急停位置 | 伸手可及 | < 500mm |
| 观察窗 | 无遮挡 | 运动区可视 |
| 维护空间 | ≥ 600mm | 侧面/后面 |
