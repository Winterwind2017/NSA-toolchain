# 典型非标设备设计案例模板

> 来源: 非标自动化行业设计经验总结
> 用途: 新项目设计参考、设计流程模板

---

## 案例 1: 直线搬运模组

### 需求
- 负载: 10kg
- 行程: 500mm
- 速度: 1m/s
- 定位精度: ±0.02mm
- 节拍: 2s/次

### 设计选型

| 部件 | 选型 | 计算依据 |
|------|------|---------|
| 伺服电机 | 400W (1.27 N·m) | T_rms=0.8 N·m, n=3000rpm |
| 减速机 | 行星 1:1 (直连) | 惯量比 < 5 |
| 丝杆 | C5 级, Φ16×导程10 | V=1m/s→n=6000rpm→需减速或导程20 |
| 导轨 | HGH20CA × 2 | 载荷校核通过 |
| 联轴器 | 膜片式 Φ14×Φ14 | 补偿偏差 |
| 传感器 | 原点: 光电; 极限: 接近 | NPN 输出 |

### 设计要点
- 丝杆两端固定-支撑安装
- 导轨安装面平面度 0.02/500
- 电机座与丝杆座同轴度 φ0.02
- 拖链弯曲半径 R ≥ 50mm

## 案例 2: 气动压装机构

### 需求
- 压装力: 2000N
- 行程: 50mm
- 速度: 可调 (50~200mm/s)
- 力监控: ±50N

### 设计选型

| 部件 | 选型 | 计算依据 |
|------|------|---------|
| 气缸 | Φ63 双作用 | F=π/4×63²×0.5=1558N, β=0.7→2226N>2000N |
| 导杆 | Φ20×2 直线轴承 | 防横向载荷 |
| 电磁阀 | 5/2 单电控 24VDC | 双作用缸标配 |
| 节流阀 | 排气节流 × 2 | 速度调节 |
| 力传感器 | 2000N 量程, 0.5%FS | 压装力监控 |
| 位移传感器 | 磁致伸缩 100mm | 压装深度控制 |
| 缓冲 | 液压缓冲器 AC1416 | 末端缓冲 |

### 设计要点
- 气缸带导杆防偏载
- 力传感器串联在压头与工件之间
- 压装过程: 快进→慢压→保压→快退
- 力-位移曲线监控 (合格判定)

## 案例 3: 视觉定位抓取

### 需求
- 工件: 30×30mm 芯片
- 定位精度: ±0.05mm
- 节拍: 1.5s/次
- 抓取方式: 真空吸盘

### 设计选型

| 部件 | 选型 | 计算依据 |
|------|------|---------|
| X/Y 模组 | 伺服+丝杆 × 2 | 行程200mm, 精度±0.01 |
| Z 轴 | 伺服+丝杆 | 行程100mm |
| R 轴 | DD马达/伺服+减速机 | 360°旋转 |
| 相机 | 500万像素面阵 | FOV 40×30mm, 精度0.01mm/pixel |
| 镜头 | 远心镜头 | 消除透视误差 |
| 光源 | 环形LED+背光 | 轮廓+表面特征 |
| 吸盘 | Φ10 真空吸盘 × 4 | 吸力校核: 安全系数 ≥ 4 |
| 真空发生器 | 喷射式 | 响应 < 50ms |

### 设计要点
- 相机固定, 工件移动 (或反之, 需标定)
- 标定板: 9点标定 + 旋转标定
- 吸盘布局: 对称分布, 防倾斜
- 真空检测: 真空开关确认吸取成功

## 通用设计流程模板

```
阶段 1: 需求分析
  □ 工件信息 (尺寸/重量/材质/来料)
  □ 工艺动作 (取/放/压/装/检)
  □ 节拍要求 (s/件)
  □ 精度要求 (定位/重复)
  □ 空间限制 (L×W×H)
  □ 环境条件 (洁净/温度/湿度)

阶段 2: 方案设计
  □ 机构类型选择
  □ 标准件初选 (电机/气缸/丝杆/导轨)
  □ 布局草图
  □ 方案评审

阶段 3: 详细设计
  □ 3D 建模 (所有零件)
  □ 干涉检查
  □ 强度/刚度校核
  □ 标准件确认

阶段 4: 工程图
  □ 零件图 (所有自制件)
  □ 装配图
  □ BOM 表
  □ 外购件清单

阶段 5: 电气设计
  □ I/O 分配表
  □ 电气原理图
  □ 线缆清单
  □ 拖链选型

阶段 6: 调试
  □ 机械调试 (运动/精度)
  □ 电气调试 (I/O/伺服)
  □ 程序调试 (PLC/视觉)
  □ 节拍优化

阶段 7: 交付
  □ 操作手册
  □ 维护手册
  □ 备件清单
  □ 验收报告
```
