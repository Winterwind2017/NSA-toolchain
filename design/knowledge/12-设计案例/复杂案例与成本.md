## 案例 4: 多工位转盘装配机

### 需求
- 工位数: 6 工位
- 节拍: 3s/件 (20件/min)
- 精度: ±0.02mm (定位)
- 功能: 上料→检测→压装→锁螺丝→视觉检→下料

### 核心选型

| 部件 | 选型 | 说明 |
|------|------|------|
| 转盘驱动 | 凸轮分割器 80DF-06 | 6工位, 精度高, 免维护 |
| 转盘直径 | Φ600mm | 6工位均布 |
| 定位销 | 锥销 Φ10 H7/m6 | 重复定位 ±0.01 |
| 压装工位 | 伺服电缸 500N | 力控+位移控 |
| 锁螺丝 | 自动锁螺丝机 | 坐标式/吹气式 |
| 视觉检测 | 面阵相机+远心镜头 | 缺陷+尺寸 |
| 上/下料 | 气缸+真空吸盘 | 或机械手 |

### 设计要点
- 凸轮分割器选型: 负载惯量 ≤ 分割器允许值
- 转盘平面度 ≤ 0.02mm
- 各工位独立气路/电路
- 安全防护: 转盘区全封闭+安全门

## 案例 5: 直线检测线

### 需求
- 产品: 手机壳 (150×75×10mm)
- 检测项: 尺寸/外观/平面度
- 节拍: 5s/件
- 精度: ±0.01mm

### 核心选型

| 部件 | 选型 | 说明 |
|------|------|------|
| 输送 | 倍速链/皮带线 | 带阻挡气缸 |
| 定位 | 顶升+定位气缸 | 到位后顶升脱离输送面 |
| 尺寸检测 | 激光位移 × 4 | 长/宽/高/平面度 |
| 外观检测 | 面阵相机 × 2 | 正面+背面 |
| 光源 | 条形光+同轴光 | 表面缺陷+尺寸 |
| 分拣 | 气缸推杆 | OK/NG 分流 |

### 设计要点
- 顶升定位: 脱离输送面, 避免振动影响
- 激光位移: 非接触, 不伤表面
- 视觉: 标定精度 ≤ 0.005mm/pixel
- 分拣: NG 品单独收集, 带计数

### 6.1 成本构成

| 类别 | 占比 | 说明 |

| 外购标准件 | 30~40% | 电机/气缸/导轨/丝杆/传感器/PLC |

|------|---------|---------|
| CNC 铣削 | 按工时 | 80~150 元/h |

### 6.4 报价公式

```
总报价 = (外购件 + 加工费 + 电气 + 装配 + 设计) × (1 + 管理利润率)

管理利润率: 15~25% (视客户/项目)
```

## 通用设计经验总结

### 节拍优化技巧
1. 并行操作: 上料与下料同时进行
2. 减少空行程: 优化运动路径
3. 提高加速度: 选大扭矩电机 (注意惯量比)
4. 凸轮分割器: 比伺服转盘更快更稳

### 精度保证技巧
1. 基准统一: 设计基准=加工基准=装配基准=测量基准
2. 调整机构: 预留 X/Y/Z/θ 调整
3. 温度补偿: 精密设备考虑热膨胀
4. 防振: 设备脚垫+独立基础

### 可靠性技巧
1. 传感器冗余: 关键工位双传感器
2. 防错设计: 工件方向/型号检测
3. 报警分级: 警告/停机/急停
4. 易损件清单: 提前备货
