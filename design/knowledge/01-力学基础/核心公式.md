# 力学基础 — 非标自动化设计必备公式

> 来源: Hibbeler《材料力学》/ 《工程力学》、Illinois/MST 公式表
> 用途: 非标设备结构强度校核、悬臂梁/支架/导轨安装面受力分析

---

## 1. 基本定义

| 物理量 | 符号 | 公式 | 单位 |
|--------|------|------|------|
| 正应力（轴向） | σ | F / A | Pa (MPa) |
| 切应力（直接剪切） | τ | V / A | Pa (MPa) |
| 正应变 | ε | δ / L₀ | 无量纲 |
| 切应变 | γ | Δx / L | rad |
| 热应变 | ε_th | α·ΔT | 无量纲 |

## 2. 本构关系（胡克定律）

```
σ = E·ε              (单向拉伸/压缩)
τ = G·γ              (纯剪切)
G = E / [2(1+ν)]     (各向同性材料)
```

| 材料 | E (GPa) | G (GPa) | ν | α (×10⁻⁶/°C) |
|------|---------|---------|------|--------------|
| Q235 钢 | 200 | 77 | 0.30 | 11.7 |
| 45# 钢 | 206 | 80 | 0.30 | 11.5 |
| SUS304 | 193 | 74 | 0.29 | 17.3 |
| 6061-T6 铝 | 69 | 26 | 0.33 | 23.6 |
| POM 赛钢 | 2.6~3.4 | 1.0 | 0.35 | 80~100 |

## 3. 轴向载荷

```
轴向变形:  δ = FL / (EA)
轴向刚度:  k = EA / L
热变形:    δ_th = α·L·ΔT
```

**非标应用**: 气缸推杆伸长量校核、丝杆轴向压缩变形。

## 4. 扭转

```
扭转剪应力:  τ = T·ρ / J
最大剪应力:  τ_max = T·c / J    (c = 外半径)
扭转角:      φ = T·L / (G·J)

极惯性矩:
  实心圆轴:  J = π·d⁴/32
  空心圆轴:  J = π·(D⁴-d⁴)/32
```

**非标应用**: 联轴器轴径校核、DD马达输出轴扭转。

## 5. 弯曲

```
弯曲正应力:  σ = M·y / I
最大弯曲应力: σ_max = M·c / I = M / S

截面模量 S = I / c

常用截面惯性矩:
  矩形 b×h:  I = b·h³/12,  S = b·h²/6
  圆 d:      I = π·d⁴/64,  S = π·d³/32
  空心管:    I = π·(D⁴-d⁴)/64

梁挠度（简支梁中点集中力）:  δ = F·L³ / (48·E·I)
梁挠度（悬臂梁端部集中力）:  δ = F·L³ / (3·E·I)
```

**非标应用**: 悬臂机械手挠度校核、铝型材跨中挠度、导轨安装面平面度。

## 6. 横向剪切

```
剪切应力:  τ = V·Q / (I·t)
剪切流:    q = V·Q / I

矩形截面最大剪应力:  τ_max = 1.5·V/A
圆形截面最大剪应力:  τ_max = 4·V/(3·A)
```

## 7. 组合载荷与应力变换

```
平面应力变换:
  σ_x' = (σx+σy)/2 + (σx-σy)/2·cos2θ + τxy·sin2θ
  τ_x'y' = -(σx-σy)/2·sin2θ + τxy·cos2θ

主应力:
  σ₁,₂ = (σx+σy)/2 ± √[((σx-σy)/2)² + τxy²]

最大面内剪应力:
  τ_max = √[((σx-σy)/2)² + τxy²]

莫尔圆:
  圆心 = (σx+σy)/2
  半径 R = √[((σx-σy)/2)² + τxy²]
```

## 8. 薄壁压力容器

```
球壳:    σ = p·r / (2·t)
圆筒:    环向应力 σ_h = p·r / t
         轴向应力 σ_a = p·r / (2·t)
```

## 9. 压杆稳定（欧拉公式）

```
临界载荷:  P_cr = π²·E·I / (K·L)²

K 值（端部约束系数）:
  两端铰支:  K = 1.0
  一端固定一端自由:  K = 2.0
  两端固定:  K = 0.5
  一端固定一端铰支:  K = 0.7

细长比:  λ = K·L / r    (r = √(I/A) 回转半径)
```

**非标应用**: 气缸活塞杆抗弯校核、长丝杆临界转速。

## 10. 应力集中

```
σ_max = K_t · σ_nom

常见 K_t 值:
  圆孔 (d/w < 0.3):  K_t ≈ 3.0
  圆角过渡 (r/d = 0.1):  K_t ≈ 2.0~2.5
  台阶轴 (r/d = 0.05):  K_t ≈ 2.5~3.0
```

**设计原则**: 非标零件避免尖角，圆角 R≥3mm，减少应力集中。

## 快速校核清单（非标设计常用）

| 场景 | 校核公式 | 安全系数 |
|------|---------|---------|
| 气缸推杆压缩 | σ = F/A ≤ [σ] | 2~3 |
| 悬臂梁端部载荷 | σ = M/S ≤ [σ], δ ≤ L/500 | 2~3 |
| 铝型材跨中挠度 | δ = 5wL⁴/(384EI) ≤ L/300 | — |
| 丝杆轴向压缩 | P < P_cr / n_st | 2~4 |
| 联轴器轴扭转 | τ = T·c/J ≤ [τ] | 2~3 |
| 螺栓预紧+外载 | σ = F/(0.7·A_s) ≤ 0.6·σ_y | 1.5~2 |
