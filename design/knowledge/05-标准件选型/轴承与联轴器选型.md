# 轴承与联轴器选型 — 非标自动化设计指南

> 来源: SKF/NSK/FAG 轴承样本、米思米联轴器选型手册、非标实务经验
> 用途: 旋转轴支撑、传动连接、电机与丝杆/减速机连接选型

---

## 1. 轴承选型

### 1.1 轴承种类与适用场景

| 轴承类型 | 承载特性 | 极限转速 | 适用场景 | 非标应用 |
|---------|---------|---------|---------|---------|
| 深沟球轴承 | 径向+少量轴向 | 高 | 通用旋转支撑 | 电机、滚轮、传送带 |
| 角接触球轴承 | 径向+轴向（单向） | 高 | 主轴、丝杆支撑 | 丝杆固定端、CNC主轴 |
| 圆锥滚子轴承 | 径向+轴向（大） | 中 | 重载、有冲击 | 减速机、车轮 |
| 圆柱滚子轴承 | 径向（大） | 高 | 重载径向 | 减速机、轧辊 |
| 推力球轴承 | 轴向（大） | 低 | 纯轴向载荷 | 千斤顶、立式丝杆 |
| 直线轴承 | 直线运动 | - | 直线导向 | 导杆气缸、滑台 |
| 交叉滚子轴承 | 径向+轴向+力矩 | 中 | 高精度旋转 | DD马达、转台 |

### 1.2 轴承选型流程

```
确定载荷方向 → 确定转速 → 计算当量动载荷 → 计算寿命 → 选择型号 → 校核静载荷
```

### 1.3 寿命计算（L10 基本额定寿命）

```
L10 = (C / P)^p × 10^6 转

其中:
  C = 基本额定动载荷 (N)
  P = 当量动载荷 (N)
  p = 寿命指数 (球轴承=3, 滚子轴承=10/3)

换算为小时:
  L10h = L10 / (60 × n)   (n = 转速 rpm)
```

### 1.4 当量动载荷

```
径向轴承: P = X·Fr + Y·Fa
  Fr = 径向载荷 (N)
  Fa = 轴向载荷 (N)
  X, Y = 径向/轴向载荷系数 (查样本)

当 Fa/Fr ≤ e 时: P = Fr (纯径向)
当 Fa/Fr > e 时: P = X·Fr + Y·Fa (联合载荷)
```

### 1.5 静载荷校核

```
C0 ≥ S0 × P0
  C0 = 基本额定静载荷 (N)
  P0 = 当量静载荷 (N)
  S0 = 静安全系数 (一般 1~2, 有冲击 2~3)
```

### 1.7 丝杆支撑轴承配置

| 配置 | 特点 | 适用场景 |
|------|------|---------|
| 固定-支撑 | 一端固定（角接触成对），一端深沟球 | 一般精度，长行程 |
| 固定-自由 | 一端固定，一端自由 | 短行程，轻载 |
| 固定-固定 | 两端都固定（角接触成对） | 高精度，高刚性 |

**角接触轴承配对方式**:
- 背对背（DB）: 抗倾覆力矩好，推荐
- 面对面（DF）: 安装方便，刚性稍差
- 串联（DT）: 承受单向大轴向力

## 2. 联轴器选型

### 2.1 联轴器种类与特性

| 联轴器类型 | 扭矩 | 转速 | 偏心补偿 | 角向补偿 | 轴向补偿 | 缓冲减振 | 适用场景 |
|-----------|------|------|---------|---------|---------|---------|---------|
| 膜片式 | 中 | 高 | 好 | 好 | 小 | 无 | 伺服电机-丝杆 |
| 梅花式 | 中 | 中 | 中 | 中 | 中 | 有 | 步进电机、一般传动 |
| 波纹管式 | 小 | 高 | 好 | 好 | 好 | 无 | 高精度、小扭矩 |
| 滑块式 | 大 | 低 | 中 | 差 | 中 | 无 | 大扭矩、低速 |
| 十字滑块 | 大 | 低 | 好 | 差 | 中 | 无 | 重载、低速 |
| 齿式 | 大 | 中 | 好 | 好 | 好 | 无 | 减速机输出、重载 |
| 万向节 | 中 | 中 | 差 | 好 | 差 | 无 | 大角度传动 |
| 刚性 | 大 | 高 | 无 | 无 | 无 | 无 | 完全同轴、高精度 |

### 2.2 联轴器选型流程

```
确定轴径 → 计算扭矩 → 选择类型 → 校核最大转速 → 确认安装尺寸
```

### 2.3 扭矩计算

```
T = 9550 × P / n   (P=功率 kW, n=转速 rpm)

选型扭矩: T_select = T × K × S
  K = 工况系数 (均匀载荷 1.0~1.5, 中等冲击 1.5~2.0, 重冲击 2.0~3.0)
  S = 安全系数 (一般 1.5~2.0)
```

### 2.4 伺服电机联轴器选型要点

1. **惯量匹配**: 联轴器惯量应尽可能小，避免影响系统响应
2. **扭转刚度**: 高刚度联轴器（膜片/波纹管）提高定位精度
3. **补偿能力**: 必须能补偿电机与丝杆的安装偏差
4. **背隙**: 零背隙联轴器用于高精度定位

**推荐配置**:
- 伺服电机 + 丝杆 → 膜片式联轴器（首选）
- 步进电机 + 丝杆 → 梅花式联轴器（性价比高）
- 高精度小扭矩 → 波纹管式联轴器

### 2.5 安装偏差允许值（参考）

| 联轴器类型 | 径向偏心 (mm) | 角向偏差 (°) | 轴向窜动 (mm) |
|-----------|-------------|------------|-------------|
| 膜片式 | 0.05~0.2 | 1~2 | ±0.5~±2 |
| 梅花式 | 0.1~0.3 | 1~2 | ±1~±3 |
| 波纹管式 | 0.1~0.2 | 2~5 | ±2~±5 |

## 3. 轴承安装与维护

### 3.1 配合选择

| 应用 | 轴配合 | 座孔配合 |
|------|--------|---------|
| 旋转内圈（一般） | k5, k6, m6 | H7 |
| 旋转内圈（重载） | n6, p6 | H7 |
| 固定内圈 | g6, h6 | H7 |
| 游动端外圈 | - | G7, H7 |

### 3.2 润滑方式

| 润滑方式 | 适用转速 | 适用温度 | 维护周期 |
|---------|---------|---------|---------|
| 润滑脂 | n < 5000 rpm | -40~120°C | 半年~2年 |
| 润滑油 | n > 5000 rpm | -30~150°C | 定期换油 |
| 油雾润滑 | 高速 | - | 连续供油 |

**润滑脂填充量**: 轴承空间的 1/3~1/2（高速 1/3，低速 1/2）

### 3.3 常见失效模式

| 失效模式 | 原因 | 对策 |
|---------|------|------|
| 疲劳剥落 | 超过寿命 | 重新计算寿命，选更大轴承 |
| 磨损 | 润滑不良、粉尘 | 改善密封，定期润滑 |
| 锈蚀 | 水分侵入 | 选密封型，防锈处理 |
| 电蚀 | 轴电流 | 绝缘轴承，接地 |
| 蠕变 | 配合过松 | 提高配合精度 |
| 烧伤 | 润滑不足、过盈过大 | 检查润滑，调整配合 |

## 4. 设计检查清单

- [ ] 轴承类型与载荷方向匹配
- [ ] L10 寿命 ≥ 设计寿命（一般 20000h）
- [ ] 静安全系数 S0 ≥ 1.5
- [ ] 实际转速 ≤ 极限转速 × 0.8
- [ ] 联轴器额定扭矩 ≥ 计算扭矩 × 工况系数 × 安全系数
- [ ] 联轴器补偿能力 ≥ 安装偏差
- [ ] 联轴器最高转速 ≥ 实际转速
- [ ] 轴承配合符合旋转/固定状态
- [ ] 润滑方式与转速匹配
- [ ] 密封方式与环境匹配
