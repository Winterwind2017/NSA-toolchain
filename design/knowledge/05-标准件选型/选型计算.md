# 标准件选型 — 电机 / 气缸 / 丝杆 / 导轨 / 轴承

> 来源: 鸣志/安川/三菱选型手册、SMC/亚德客气缸手册、THK/HIWIN丝杆导轨手册、米思米选型指南
> 用途: 非标自动化设备标准件选型计算

## 1. 伺服电机选型

> 先判定种类：`电机种类选型.md` + `motor.recommend_type`。连转轴用 `drive_power`，开环点位用 `stepper_selection`。本节只做伺服校核公式。

### 1.1 选型流程

```
明确运动条件 → 计算负载惯量 → 预选电机 → 计算转矩 → 校核 → 确认型号
```

### 1.2 惯量计算

```
丝杆传动:  J_L = m · (P_b / 2π)²
带轮传动:  J_L = m · r²
旋转体:    J = ½ · m · r²    (实心圆柱)

总负载惯量:  J_total = J_L + J_coupling + J_gear/i²

惯量比:  R = J_total / J_M
推荐值:  快速定位 R ≤ 3~5, 慢速定位 R ≤ 5~8, 一般 R ≤ 10
```

### 1.3 转矩计算

```
摩擦转矩:  T_f = μ · m · g · P_b / (2π · η)
加速转矩:  T_a = (J_M + J_total) · 2π · n / (60 · t_a)
总加速转矩: T_acc = T_a + T_f
匀速转矩:  T_run = T_f
减速转矩:  T_dec = T_a - T_f    (可能为负)

RMS 转矩:  T_rms = √[(T_acc²·t_a + T_run²·t_b + T_dec²·t_d) / (t_a+t_b+t_d)]

校核条件:
  T_rated ≥ T_rms · n_s    (n_s = 1.2~1.5 安全系数)
  T_max ≥ T_acc · n_s
  n_rated ≥ n_required
```

### 1.4 常用伺服电机参考

| 功率 (kW) | 额定转矩 (N·m) | 惯量 (×10⁻⁴ kg·m²) | 额定转速 (rpm) |
|:---------:|:-------------:|:------------------:|:-------------:|
| 0.1 | 0.32 | 0.13 | 3000 |
| 0.2 | 0.64 | 0.25 | 3000 |
| 0.4 | 1.27 | 0.66 | 3000 |
| 0.75 | 2.39 | 2.77 | 3000 |
| 1.0 | 3.18 | 8.2 | 3000 |
| 1.5 | 4.77 | 14 | 3000 |
| 2.0 | 6.37 | 30.6 | 3000 |
| 3.0 | 9.55 | 77 | 3000 |

## 2. 气缸选型

> 先判定种类：`气动元件选型.md` + `pneumatic.recommend_actuator`。阀走 P11。本节只做缸径/行程/缓冲/横向载荷公式。

### 2.1 选型流程

```
确定负载力 F → 选负载率 β → 算理论出力 F₀ → 选缸径 D → 选行程 → 选系列 → 选缓冲 → 选磁性开关
```

### 2.2 核心公式

```
理论推力:  F₀ = (π/4) · D² · P
理论拉力:  F₀' = (π/4) · (D² - d²) · P    (d ≈ 0.3D)

实际出力:  F_A = F₀ · β

负载率 β 选取:
  静负载 (夹紧):  β = 0.7~0.8
  低速 (<100mm/s):  β = 0.5~0.65
  中速 (100~500mm/s):  β = 0.35~0.5
  高速 (>500mm/s):  β = 0.25~0.35

缸径圆整:  D = √(4·F / (π·P·β))  → 取标准值
```

### 2.3 标准缸径系列 (mm)

6, 10, 16, 20, 25, 32, 40, 50, 63, 80, 100, 125, 160, 200, 250, 320

### 2.4 行程选择原则

- 不选满行程（防活塞撞缸盖）
- 夹紧机构加 10~20mm 余量
- 优先选标准行程

### 2.5 缓冲选择

| 类型 | 适用缸速 | 特点 |
|------|---------|------|
| 无缓冲 | <100 mm/s | 成本低 |
| 橡胶缓冲 | 100~300 mm/s | 简单 |
| 气缓冲 | 300~500 mm/s | 可调 |
| 液压缓冲器 | >500 mm/s | 高精度，可调 |

### 2.6 横向载荷校核

```
允许横向载荷 ≈ 最大推力的 1/20
超出 → 改用带导杆气缸或加外部导轨
```

## 3. 滚珠丝杆选型

### 3.1 选型流程

```
确定导程 → 确定精度等级 → 计算轴向载荷 → 选直径 → 校核寿命 → 校核临界转速 → 校核 DN 值
```

### 3.2 导程计算

```
P_b = V_max · 60 / (n_R · i)

V_max = 最大线速度 (mm/s)
n_R = 电机额定转速 (rpm)
i = 传动比 (直连 i=1)
```

### 3.3 精度等级

| 等级 | 300mm 行程变动量 (μm) | 典型应用 |
|:----:|:-------------------:|---------|
| C3 | ±3.5 | 精密机床、半导体设备 |
| C5 | ±18 | 一般自动化设备 |
| C7 | ±50 | 搬运、输送 |
| C10 | ±210 | 粗定位 |

### 3.4 寿命计算

```
L = (C_a / (F_m · f_w))³ · 10⁶    (转)

L_h = L / (60 · n_m)              (小时)

C_a = 额定动载荷 (N)
F_m = 等效轴向载荷 (N)
f_w = 载荷系数 (平稳 1.0~1.2, 一般 1.2~1.5, 冲击 1.5~2.0)
n_m = 平均转速 (rpm)
```

### 3.5 临界转速

```
n_cr = f · (d_r / L²) · 10⁷

f = 安装系数:
  固定-自由: 3.4
  固定-支撑: 15.1
  固定-固定: 21.9

d_r = 丝杆沟槽底径 (mm)
L = 安装间距 (mm)

校核: n_max ≤ 0.8 · n_cr
```

### 3.6 DN 值校核

```
DN = D · n ≤ 50000~70000

D = 丝杆公称直径 (mm)
n = 转速 (rpm)
```

## 4. 直线导轨选型

### 4.1 载荷计算

```
各滑块等效载荷需考虑力矩影响:
P = F_r / n ± M_x / (2·l_y) ± M_y / (2·l_x)

F_r = 径向总载荷
M_x, M_y = 绕 X/Y 轴的力矩
l_x, l_y = 滑块间距
n = 滑块数量
```

### 4.2 寿命计算

```
L = (C / (f_w · P))³ · 50    (km, 球型)
L = (C / (f_w · P))^(10/3) · 50    (km, 滚子型)

L_h = L · 10⁶ / (2 · l_s · n₁ · 60)    (小时)

C = 基本额定动载荷
P = 等效载荷
f_w = 载荷系数
l_s = 行程 (mm)
n₁ = 每分钟往复次数
```

### 4.3 静安全系数

```
f_s = C₀ / P₀ ≥ 1~2 (普通) / ≥ 2~3 (振动/冲击)

C₀ = 基本额定静载荷
P₀ = 最大静载荷
```

### 4.4 精度等级

| 等级 | 行走平行度 (μm/1000mm) | 应用 |
|:----:|:--------------------:|------|
| 普通 N | 20 | 一般搬运 |
| 高级 H | 10 | 自动化设备 |
| 精密 P | 5 | 精密定位 |
| 超精密 SP | 3 | 半导体/光学 |

## 5. 轴承选型速查

| 类型 | 承载方向 | 转速能力 | 典型应用 |
|------|---------|:-------:|---------|
| 深沟球 | 径向+双向轴向 | 高 | 通用 |
| 角接触球 | 径向+单向轴向 | 高 | 丝杆支撑 |
| 圆锥滚子 | 径向+轴向 | 中 | 重载 |
| 推力球 | 纯轴向 | 低 | 垂直轴 |
| 滚针 | 径向(小空间) | 中 | 紧凑设计 |

### 轴承寿命

```
L₁₀ = (C / P)³ · 10⁶    (球轴承, 转)
L₁₀ = (C / P)^(10/3) · 10⁶    (滚子轴承, 转)
L₁₀h = L₁₀ / (60 · n)    (小时)
```
