# 非标电机种类选型

> 线索: B站 BV13t896UEWL P8《电机的选型》片头脑图六块：分类、种类区别、按工况定种类、驱动电机、步进、伺服。该集约 2h05 且无字幕，不收录口播型号表；正文按非标方案决策补全。
> 计算: `design_calc.motor.recommend_type` / `drive_power` / `stepper_selection`
> 伺服惯量、峰值、RMS 仍用 `motor.servo_selection`，公式见同目录 `选型计算.md` §1。减速机用 `reducer`。传动路线用 `transmission.recommend_drive`。

先问要不要定位、转得快不快、精度、是不是 24h 连转，再定种类。不要默认上伺服。

---

## 1. 分类：驱动 / 执行 / 直驱

电机是原动机。非标里先按**用途**分，再按电源和结构。

| 用途 | 常见种类 | 干什么 |
|------|----------|--------|
| 驱动电机 | 三相异步、减速电机、调速/变频电机 | 给空压机、液压泵、风机、皮带线提供连续动力 |
| 执行电机 | 步进、交流伺服 | 按脉冲或指令走位置、速度、转矩 |
| 直驱 | DDL 直线电机、DDR 力矩电机 | 去掉丝杆/减速机，负载直接装在动子上 |

结构对照（选型时能听懂厂家话即可）：

| | 同步 | 异步 |
|--|------|------|
| 转子 | 自己有磁场（永磁或励磁） | 靠定子感应出磁场 |
| 转速 | 跟磁场同步 | 比磁场慢（转差） |
| 过载 | 过载会失步/失同步 | 堵转转矩大，但效率低、发热 |
| 能耗 | 相对省 | 工频异步最普及，不节能 |
| 非标用法 | 伺服、步进、部分永磁直驱 | 泵、风机、输送、空压机 |

有刷 vs 无刷：设备上默认无刷。有刷碳刷要换、火花、脏，只出现在廉价直流或特殊场合。

## 2. 按工况定种类

```
要不要闭环定位？
 ├─ 否，且 24h 连转（泵/风机/空压/单纯输送） → 三相异步 ± 减速机/变频
 ├─ 否，间歇慢转、只要转起来（搅拌、简单翻转） → 减速电机
 └─ 是，要走到位
      ├─ 精度极高、背隙不能有、预算够 → DDR / DDL
      ├─ 高速、频繁加减速、精度 ≤0.05 mm、垂直轴 → 交流伺服
      └─ 低速轻载、成本敏感、精度可以放到 0.1 mm 级 → 步进
```

| 种类 | 精度量级 | 速度 | 过载表现 | 成本 | 典型用法 |
|------|----------|------|----------|------|----------|
| 三相异步 | 不定位 | 工频或变频 | 堵转发热，不会“丢步”概念 | 低 | 泵、风机、皮带连转 |
| 减速电机 | 开环转位很差 | 出轴慢 | 靠减速比出力 | 低 | 简单翻转、阀门、挡停转位凑合 |
| 步进 | ±0.05~0.2 mm（看机构） | 有效区偏低 | **丢步**，位置丢了不知道 | 低 | 轻载点位、送料、调节 |
| 交流伺服 | ±0.01~0.05 | 额定 3000 rpm 常用 | 过载报警，闭环可拉回 | 中高 | 模组、飞拍、压装、龙门 |
| DDR/DDL | 角秒~μm 级 | 看惯量 | 闭环 | 高 | 转台、晶圆、长行程高动态 |

决策顺序：

1. 定位还是连转  
2. 重复定位能不能放到 0.1 mm 以上  
3. 电机轴是否经常 > 600 rpm（步进矩频开始塌）  
4. 是否频繁加减速（看 RMS / 看丢步）  
5. 垂直轴有没有抱闸  
6. 能不能接受减速机背隙（不能就直驱或消隙）

## 3. 驱动电机：功率公式

连续旋转用功率，不要套伺服 RMS。

```
旋转:  P(kW) = T(N·m) · n(rpm) / 9550
直线:  P(W) = F(N) · v(m/s)

入电机:  P_motor = P / η · k
```

- `η`：机构效率，皮带/链/蜗轮要往低取，片头例常用 0.8  
- `k`：安全系数。工况清楚 1.5~2；冲击、惯量说不清 2.5~3；片头翻转例用到 5，那是未知冲击的保守取法，**不要把 k=5 套到伺服定位轴上**

异步电机功率档（kW）：0.12 / 0.18 / 0.25 / 0.37 / 0.55 / 0.75 / 1.1 / 1.5 / 2.2 / 3.0 / 4.0 / 5.5 / 7.5 …

低速大扭矩先定出轴 `n` 和 `T`，再选 `i`，使电机落在 1000~1500 rpm（4 极工频）或变频器高效区，不要让电机在几十 rpm 硬顶。

片头翻转例（量级，不抄型号）：`T=147.5 N·m`、`n=29 rpm` → `P≈0.45 kW`，选 750 W、`i=50`，出轴约 30 rpm / 219 N·m，相对 147.5 有余量。

## 4. 步进电机

开环：驱动器发脉冲，电机走一步。没有编码器时，丢步就是位置误差。

### 4.1 必须记住的特性

- **保持转矩**只是接近零速的静力矩。工作转速要查**矩频曲线**，高速段转矩会掉一截  
- 低频共振（常见一百多 Hz 量级）：机座抖、啸叫、更容易丢步；细分、加阻尼、避开该转速  
- 通电就发热，表面温度高是常态，但别靠壳体当结构件的热源  
- 过载、加速过猛、机械卡死 → 丢步；系统不会报警  
- 惯量比可比伺服松：输送类到 10 左右经常还能用；高速定位仍应压到 10 以内，必要时加减速

### 4.2 选型计算

丝杆/同步带直线（负载折到电机轴）：

```
J_L = m · (P_b / 2π)²
n_load = v · 60 / P_b          (v: mm/s, P_b: mm)
n_motor = n_load · i
β = 2π · n_motor / (60 · t_a)  rad/s²
T_f = (μmg + F) · P_b / (2π η)
T_a = (J_M + J_L/i²) · β
T_need = k · (T_a + T_f/i) / η

脉冲:  f(pps) = n_motor / 60 · (360 / θ) · 细分
两相混合默认 θ = 1.8° → 整步 200 脉冲/转
```

`k`：平稳 1.5~2，加速/输送 2~3。算出的是**该转速下需要的转矩**，拿矩频曲线上对应 pps 的转矩比，不要只比保持转矩。

法兰量级（两相混合，保持转矩大致范围）：

| 法兰 | 保持转矩 | 适用 |
|------|----------|------|
| 20/28 | 0.02~0.13 N·m | 微调、极轻载 |
| 42 | 0.2~0.8 | 小型模组、送料 |
| 57 | 0.5~2.2 | 非标最常用 |
| 86 | 2~8 | 较大惯量、低速 |

加减速机：出力变大、惯量按 `1/i²` 折算、电机转速升高。升高后必须重新看矩频——`i` 太大把电机送进无力区，得不偿失。

片头输送例（量级）：`T_总≈0.072 N·m`，`k=2` → 0.16 N·m；`i=5` 后电机约 0.032 N·m，选 28 机座 0.1 N·m 保持转矩；折算惯量比约 11，标注“输送机足够了”。**这是慢速输送，不能推广到高速飞拍。**

### 4.3 反模式

- 用保持转矩当 600 rpm 的可用转矩  
- 垂直轴步进还不加刹车  
- 大惯量转盘开环点位还追求节拍  
- 把步进当伺服闭环用却不加编码器（闭环步进是另一档，按伺服流程校核）

## 5. 伺服电机

闭环：编码器把位置送回驱动器，正常不会静默丢步。非标定位轴的默认解。

校核三件套（公式见 `选型计算.md`）：

1. `T_rated ≥ T_rms · n_s`  
2. `T_max ≥ T_acc · n_s`  
3. `n_rated ≥ n_max`，惯量比快速定位 3~5、一般 ≤10  

`n_s` 取 1.2~1.5。垂直轴选带抱闸。减速机只为扭矩、惯量比、转速匹配服务，不是“有伺服就一定要加”。

直驱：负载惯量就是电机惯量的一部分，惯量比公式变了，按厂家样本；机械上要处理电缆、冷却、防护。预算和安装面不够时，伺服+谐波/行星通常更合适。

## 6. 和传动、气缸的边界

- 两点到位、力够、不要中间位 → 先评估气缸，不是电机  
- 已经决定电动直线轴 → 先 `transmission.recommend_drive`（丝杆/带/齿条），再选步进还是伺服  
- 电机种类选完才进 `servo_selection` / `stepper_selection` / `drive_power`
