# 非标气动元件选型

> 线索: B站 BV13t896UEWL P9《气动元件选型》片头脑图十块：压缩机→冷却→储气→主滤→干燥→气源处理→控制→执行→配件→真空。该集约 2h10 且无字幕，不收录口播型号表；正文按 SMC/亚德客惯例 + 非标方案决策补全。
> 计算: `design_calc.pneumatic.recommend_actuator` / `recommend_frl` / `air_consumption` / `vacuum_cup_check`
> 缸径、行程、横向载荷、缓冲仍用 `cylinder`，公式见同目录 `选型计算.md` §2。电磁阀见 `08-减速机与传感器/电磁阀选型.md` 与 `pneumatic.valve_select`。

先问动作是直线、旋转、夹持还是吸附，再定元件。不要一上来就画一根标准缸。

---

## 1. 气动系统十条链

设备图上从气源到执行器应按这条链点名，缺一环后面全是“气缸慢、积水、阀岛糊”。

```
空压机 → 后冷却器 → 储气罐 → 主路过滤器 → 干燥机
      → 气源处理（过滤+减压+油雾，按需）
      → 控制元件（电磁阀 / 手动阀 / 节流）
      → 执行元件（气缸 / 手指 / 真空）
      → 配件（接头、消声器、磁性开关、液压缓冲）
```

厂务气源（压缩机、干燥机、大罐）通常不在非标 BOM 里，但要**向客户要气源品质**：压力、露点、油分。机台侧从进气球阀 + 三联件写起。

---

## 2. 气源处理

| 元件 | 作用 | 非标怎么选 |
|------|------|------------|
| 过滤器 | 固体颗粒、水分、油污 | 一般 40 μm；阀岛/精密 5 μm；分水效率希望 >80% |
| 减压阀 | 稳压、降到工作压力 | 气缸常用 **0.4~0.6 MPa**；真空发生器另路，不要跟夹紧缸抢压 |
| 油雾器 | 给需要油雾润滑的老式缸供油 | **无油缸、真空、传感器、阀岛禁止加油雾** |

压降要小：滤芯堵了先表现为气缸变慢，不要先换更大的阀。

手动阀：检修排气、气源切断用 3 通手阀或球阀，装在三联件前。旋转手柄/推拉阀（片头 3H/4H、4HV 一类）给调试或安全泄压，不要用它当节拍执行阀。

---

## 3. 控制：速度默认排气节流

回路骨架：

| 执行器 | 阀 | 调速 |
|--------|----|------|
| 单作用 / 弹簧夹紧 | 3/2 | 单向节流 |
| 双作用 | 5/2（最常用） | **两侧排气节流（meter-out）** |
| 要中停 | 5/3，见 P11 | 中封不能当刹车 |

```
水平、一般垂直下降 → 排气节流（背压稳，少爬行）
垂直提升、要防失速   → 才考虑进气节流
末端要软着陆         → 缸自带气缓冲 + 排气节流；动能大再加液压缓冲器
```

阀的 9 步选型不在本页，走 `电磁阀选型.md`。

## 4. 执行元件：先定种类

片头脑图四步：**气缸 → 品牌（SMC / 亚德客）→ 种类 → 参数**。品牌按客户指定或备件习惯，种类按下表。

| 种类 | 适用 | 别用在 |
|------|------|--------|
| 标准双作用 | 通用直线两点到位 | 行程很长还要活塞杆伸出机架外 |
| 薄型/紧凑 | 行程短、轴向空间紧 | 大偏载、长行程 |
| 带导杆 / 三轴 | 有横向力、要抗扭 | 只要出力、空间极紧 |
| 无杆-机械接合 | 长行程、载荷和力矩都有 | 密封要求极高、粉尘会卡滑块 |
| 无杆-磁耦合 | 要隔离、较干净 | 大负载（磁力会滑脱） |
| 旋转气缸 | 90°/180°/270° 有限转角 | 连续旋转（改电机） |
| 气动手指 | 刚性件夹持、开闭角明确 | 软包、多孔、易碎薄膜（改真空） |
| 夹紧气缸 | 杠杆/肘节夹紧、力大行程短 | 当普通长行程缸用 |
| 气液增压缸 | 压装、冲裁，要几吨力但气源仍是 0.5 MPa | 要位置伺服的压装（改伺服压机） |

决策顺序：

1. 夹持还是吸附还是直线/旋转  
2. 行程是否 > 400 mm（活塞杆细长、无杆开始划算）  
3. 有没有横向力（超过推力约 1/20 必须导杆或外导轨）  
4. 轴向空间够不够（不够上薄型）  
5. 力是否远超 Φ80~100 气缸（增压或液压）  
6. 两点到位是否够（中间位、力可控 → 不要气缸，改伺服）

缸径、行程、缓冲仍用 `cylinder.select_bore` / `select_stroke` / `buffer_selection`。横向力用 `check_lateral_load`。

无杆气缸：机械接合出力和抗矩更好；磁耦合泄漏少、过载会“丢步”式滑脱。长行程无杆必须外加导轨或选带导轨滑块的系列，不要把滑台当梁。

气动手指：平行开闭是默认；要张很大再选 180° 开闭。夹持力按工件摩擦和姿态取安全系数，薄片侧夹容易飞。手指不是手腕——力矩交给模组或导杆缸。

## 5. 真空

三件套：**吸盘 + 发生器（或泵）+ 破坏/检测**。

吸盘材质：

| 材质 | 场合 |
|------|------|
| 丁腈 NBR | 一般工件默认 |
| 硅橡胶 | 食品、高温、易留痕的光滑件 |
| 氟橡胶 | 油、溶剂 |
| 聚氨酯 | 耐磨、纸箱/稍粗表面 |
| 波纹/海绵/异形 | 薄膜、袋装、不平整 |

形状：平面件用扁平；曲面/柔性用波纹；漏气件加大直径或加数量，不要把真空度当无限。

发生器 vs 泵：工位少、间断吸取用发生器（耗气，要单独减压）；工位多、长时间真空用泵。水平安全系数 ≥4，垂直/加速 ≥8，计算走 `vacuum_cup_check`。多孔、编织袋发生器吸不住就改夹爪或托盘，不要无限加大发生器。

## 6. 配件

- **气管**：按缸径，`pneumatic.pipe_size`；阀到缸尽量 <1 m  
- **接头**：快插最常用；快拧给金属管或要防拔；C 型快换给气枪/保养口，不要当设备内永久接头满机飞  
- **消声器**：排气口必装，堵了就是“气缸突然变慢”  
- **磁性开关**：带磁缸 + 槽安装；完成信号不要用纯延时  
- **液压缓冲器**：高速、大质量末端；按吸收能量和撞击速度选，不是装饰

## 7. 和电机、阀的边界

- 两点到位、力够、不要中间位 → 气缸  
- 要位置、速度曲线、力控 → `motor.recommend_type`  
- 阀岛、中封/中泄、单双电 → P11，不要在本页选阀型号  
- 无油缸加油雾、中封当刹车、气管 3 m：反模式见电磁阀文

图纸：执行器写清系列种类、缸径×行程、有无磁、安装方式；气源口写工作压力；真空回路单独出图，不要和夹紧缸共减压阀。
