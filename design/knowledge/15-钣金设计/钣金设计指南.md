# 钣金设计指南

## 一、常用材料

| 材料 | 厚度范围 | 特点 | 应用场景 |
|------|----------|------|----------|
| 冷轧钢板 (SPCC) | 0.5-3.0mm | 成本低，易冲压 | 机架、罩壳、安装板 |
| 不锈钢 (SUS304) | 0.5-2.0mm | 耐腐蚀，美观 | 食品设备、医疗设备 |
| 铝合金 (5052) | 1.0-4.0mm | 重量轻，导热好 | 散热片、轻量化结构 |
| 镀锌钢板 (SECC) | 0.5-2.5mm | 防锈，易焊接 | 电气柜、设备外壳 |

## 二、折弯系数

### 折弯扣除计算

```
折弯扣除 = 板厚 × 系数
90°折弯扣除:
- 铝板: 1.6 × t
- 钢板: 1.7 × t
- 不锈钢: 1.8 × t
```

### 展开长度计算

```
展开长度 = 外形尺寸1 + 外形尺寸2 - 折弯扣除
```

## 三、设计规范

### 最小折弯高度

```
最小折弯高度 = 下模槽宽 / 2 + 板厚
下模槽宽通常取板厚的 6-8 倍
```

### 最小孔径

```
冲孔直径 ≥ 板厚
方孔边长 ≥ 板厚
```

### 孔边距

```
孔中心到折弯线距离 ≥ 板厚 + 孔半径
否则孔会变形
```

## 四、常用结构

### 加强筋

- 凸起高度: 0.5-1.5 × t
- 间距: 50-100mm
- 作用: 增加刚性，减少变形

### 翻边

- 翻边高度: 1.0-1.5 × d (d为孔径)
- 作用: 增加螺纹连接强度

### 圆角

- 外圆角 R ≥ 1.0mm
- 内圆角 R ≥ 0.5mm
- 避免尖角，减少应力集中

## 六、表面处理

| 处理方式 | 特点 | 应用 |
|----------|------|------|
| 喷塑 | 颜色多，耐磨 | 设备外罩 |
| 电镀 | 光亮，防锈 | 装饰件 |
| 拉丝 | 美观，防指纹 | 不锈钢外观件 |
| 阳极氧化 | 耐腐蚀，导电 | 铝合金件 |
