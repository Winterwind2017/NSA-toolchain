## 2. 热处理工艺选择

| 工艺 | 适用材料 | 硬度范围 | 目的 | 典型应用 |
|------|---------|---------|------|---------|
| 调质 (淬火+高温回火) | 45#, 40Cr | HRC 25~35 | 综合力学性能 | 轴、齿轮、连杆 |
| 表面淬火 | 45#, 40Cr | HRC 45~55 | 表面耐磨 | 导轨面、凸轮面 |
| 渗碳淬火 | 20Cr, 20CrMnTi | 表面 HRC 58~62 | 表面硬+心部韧 | 齿轮、销轴 |
| 渗氮 | 38CrMoAl, 40Cr | 表面 HV 800~1200 | 耐磨+耐疲劳 | 精密轴、丝杆 |
| 退火 | 所有钢 | 降低硬度 | 消除应力/改善切削 | 焊接后、铸件 |
| 正火 | Q235, 45# | 细化晶粒 | 改善组织 | 锻件预处理 |

## 4. 选材决策树

```
需要耐腐蚀？
├── 是 → 食品/医疗？ → SUS304 (钣金) / SUS303 (机加件)
│       一般防锈？ → 镀锌钢 / 阳极氧化铝
└── 否 → 需要轻量化？
         ├── 是 → 受力大？ → 7075-T6
         │       受力中？ → 6061-T6
         │       耐磨？   → POM / MC尼龙
         └── 否 → 需要热处理？
                  ├── 是 → 综合性能？ → 45# (调质)
                  │       高强度？   → 40Cr (调质+表面淬火)
                  │       高耐磨？   → GCr15 / 渗碳钢
                  └── 否 → Q235 (焊接/结构件)
```

## 5. 异种材料接触注意事项

| 组合 | 风险 | 措施 |
|------|------|------|
| 铝+钢 | 电偶腐蚀 | 加绝缘垫片/涂防蚀膏 |
| 铝+铜 | 严重电偶腐蚀 | 必须隔离 |
| 不锈钢+碳钢 | 碳钢锈蚀加速 | 隔离或碳钢镀锌 |
| POM+金属 | 无电偶风险 | 可直接接触 |
