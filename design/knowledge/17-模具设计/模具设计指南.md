# 模具设计指南

## 一、常用模具类型

| 类型 | 特点 | 应用 |
|------|------|------|
| 冲压模 | 生产效率高，成本低 | 钣金件、壳体 |
| 注塑模 | 精度高，复杂形状 | 塑料件、外壳 |
| 压铸模 | 精度高，表面好 | 铝合金压铸件 |
| 吹塑模 | 中空制品 | 瓶子、容器 |

## 二、冲压模设计

### 冲压工序

| 工序 | 特点 |
|------|------|
| 落料 | 分离材料，获得所需形状 |
| 冲孔 | 在工件上冲孔 |
| 弯曲 | 将板料弯成一定形状 |
| 拉深 | 将板料制成空心件 |
| 翻边 | 沿孔边缘翻出边缘 |

### 冲压力计算

```
冲压力 = 周长 × 板厚 × 抗剪强度
抗剪强度: 钢板 ≈ 350 MPa
```

### 间隙选择

```
双面间隙 = 板厚 × (5-10)%
软材料: 5%
硬材料: 10%
```

## 三、注塑模设计

### 模具结构

| 结构 | 说明 |
|------|------|
| 型腔 | 成型制品外形 |
| 型芯 | 成型制品内形 |
| 浇注系统 | 熔融塑料进入型腔的通道 |
| 冷却系统 | 控制模具温度 |
| 顶出系统 | 顶出制品 |

### 收缩率

```
收缩率 = (模具尺寸 - 制品尺寸) / 制品尺寸
常用材料收缩率:
- ABS: 0.5%
- PP: 1.5%
- PC: 0.7%
- PA66: 1.5%
```

## 四、压铸模设计

### 压铸特点

- 高压高速填充
- 尺寸精度高
- 表面质量好
- 生产效率高

### 常用合金

| 合金 | 特点 | 应用 |
|------|------|------|
| 锌合金 | 熔点低，易成型 | 装饰件、小五金 |
| 铝合金 | 重量轻，导热好 | 汽车零件、外壳 |
| 镁合金 | 更轻，比强度高 | 3C产品、汽车零件 |

## 五、设计规范

### 拔模斜度

```
塑料件: 1°-2°
压铸件: 1°-3°
冲压件: 0.5°-1°
```

### 圆角

```
内圆角 R ≥ 0.5mm
外圆角 R = 内圆角 + 壁厚
避免尖角，减少应力集中
```

### 壁厚

```
均匀壁厚 (推荐 2-3mm)
避免壁厚突变
避免局部厚大 (易缩孔)
```

## 六、常用模具钢

| 钢号 | 特点 | 应用 |
|------|------|------|
| P20 | 预硬，易加工 | 一般注塑模 |
| 718 | 抛光性好 | 透明件模具 |
| H13 | 耐热，耐磨 | 压铸模 |
| Cr12MoV | 耐磨，变形小 | 冲压模 |
| S136 | 耐腐蚀，抛光好 | 透明件、耐腐蚀模具 |
