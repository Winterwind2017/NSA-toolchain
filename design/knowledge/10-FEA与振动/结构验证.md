# FEA 与振动分析基础 — 非标设备结构验证

> 来源: Cook《有限元分析概念与应用》、Rao《机械振动》、SolidWorks Simulation 手册
> 用途: 结构强度验证、共振规避、刚度优化

---

## 1. FEA 基础概念

### 1.1 分析类型

| 类型 | 用途 | 非标应用场景 |
|------|------|------------|
| 静力分析 | 应力/变形 | 机架/悬臂/支架强度校核 |
| 模态分析 | 固有频率/振型 | **共振规避（最重要）** |
| 谐响应 | 稳态振动响应 | 电机激励下的振动 |
| 瞬态动力学 | 冲击/碰撞 | 气缸冲击/急停 |
| 屈曲分析 | 失稳临界载荷 | 细长杆/薄壁件 |
| 热分析 | 温度场/热应力 | 焊接变形/电机发热 |

### 1.2 静力分析流程

```
1. 建模简化 (去倒角/螺纹/小孔)
2. 赋材料属性 (E, ν, ρ, σ_y)
3. 网格划分 (四面体/六面体, 关键区加密)
4. 施加约束 (固定/铰支/滑动)
5. 施加载荷 (力/压力/重力/离心力)
6. 求解
7. 查看结果:
   - von Mises 应力 → 对比 σ_y / n
   - 位移 → 对比允许挠度
   - 安全系数云图 → 找薄弱区
```

### 1.3 网格质量要求

| 指标 | 推荐值 | 说明 |
|------|--------|------|
| 单元尺寸 | 壁厚的 1~2 倍 | 关键区加密 |
| 雅可比比 | > 0.6 | < 0.3 需重划 |
| 纵横比 | < 5 | > 10 影响精度 |
| 网格收敛 | 应力变化 < 5% | 加密后对比 |

### 1.4 结果判读

```
应力判读:
  σ_max < σ_y / n  →  OK
  σ_max > σ_y / n  →  加厚/加筋/换材料

变形判读:
  δ < L/500  →  OK (一般结构)
  δ < L/1000 →  OK (精密结构)

应力集中:
  尖角处应力奇异 → 忽略或加圆角后重算
  真实应力集中 → 关注 K_t 值
```

## 2. 振动分析

### 2.1 固有频率

```
单自由度:  f_n = (1/2π) · √(k/m)

k = 刚度 N/m
m = 质量 kg

多自由度:  [K]{φ} = ω²[M]{φ}  (特征值问题)
```

### 2.2 共振规避原则

```
工作频率 f_w 与固有频率 f_n 的关系:

  f_w < 0.7 · f_n   →  安全 (低频区)
  0.7·f_n < f_w < 1.3·f_n  →  共振区！必须避开
  f_w > 1.3 · f_n   →  安全 (高频区/隔振)

非标设备常见激励源:
  伺服电机: 0~100 Hz (转速/60)
  气缸冲击: 宽带脉冲
  输送带: 辊筒转速频率
```

### 2.3 提高固有频率的方法

| 方法 | 效果 | 代价 |
|------|------|------|
| 增加截面惯性矩 | f_n ∝ √I | 重量增加 |
| 缩短悬臂长度 | f_n ∝ 1/L² | 空间受限 |
| 加加强筋 | 显著提高 | 加工成本 |
| 减重 | f_n ∝ 1/√m | 强度可能不足 |
| 换高 E 材料 | f_n ∝ √E | 成本增加 |

### 2.4 阻尼与减振

```
阻尼比 ζ:
  ζ < 0.01  →  金属结构 (几乎无阻尼)
  ζ = 0.02~0.05  →  螺栓连接结构
  ζ = 0.05~0.1  →  焊接结构
  ζ > 0.1  →  加阻尼材料

减振措施:
  1. 橡胶减震垫 (隔振)
  2. 阻尼贴片 (耗能)
  3. 调谐质量阻尼器 (TMD)
  4. 改变结构频率 (避开激励)
```

## 3. 非标设备 FEA 检查清单

- [ ] 机架整体模态 > 工作频率 × 1.5？
- [ ] 悬臂端挠度 < L/500？
- [ ] 最大 von Mises < σ_y / 2？
- [ ] 应力集中处是否加了圆角？
- [ ] 气缸冲击工况是否校核？
- [ ] 螺栓预紧力是否建模？
- [ ] 网格是否收敛？
