# FEA 精通级 — 网格策略 / 后处理 / 振动测试 / 软件操作

> 来源: Cook《FEA 概念与应用》、SolidWorks Simulation/ANSYS 手册、振动测试标准
> 用途: FEA 实操、结果判读、振动测试

---

## 1. 网格策略

### 1.1 单元类型选择

| 单元类型 | 适用 | 精度 | 计算量 |
|---------|------|:----:|:-----:|
| 四面体 (Tet) | 复杂几何 | 中 | 低 |
| 六面体 (Hex) | 规则几何 | **高** | 中 |
| 壳单元 (Shell) | 薄壁件 (t/L<1/10) | 高 | **低** |
| 梁单元 (Beam) | 型材/杆件 | 中 | **极低** |

### 1.2 网格尺寸策略

```
全局网格:  特征尺寸的 1/5~1/10
关键区加密: 全局的 1/2~1/3
应力集中区: 圆角处至少 3 层单元
薄壁件:  厚度方向 ≥ 2 层

网格收敛验证:
  1. 粗网格求解 → 记录 σ_max
  2. 网格尺寸减半 → 记录 σ_max'
  3. 误差 = |σ_max' - σ_max| / σ_max'
  4. 误差 < 5% → 收敛
  5. 误差 > 5% → 继续加密
```

### 1.3 网格质量指标

| 指标 | 合格 | 优秀 | 需重划 |
|------|:----:|:----:|:-----:|
| 雅可比比 | > 0.6 | > 0.8 | < 0.3 |
| 纵横比 | < 5 | < 3 | > 10 |
| 歪斜角 | < 30° | < 15° | > 60° |
| 翘曲角 (壳) | < 5° | < 2° | > 15° |

## 2. 后处理判读

### 2.1 应力云图判读

```
1. 先看全局 → 找最大应力位置
2. 区分真实应力 vs 奇异应力:
   - 尖角/点载荷/约束处 → 奇异 (忽略)
   - 圆角/截面变化处 → 真实 (关注)
3. 对比许用应力:
   σ_max < σ_y / n  →  OK
   σ_max > σ_y / n  →  需优化
4. 查看应力梯度:
   梯度大 → 应力集中, 加圆角
   梯度小 → 均匀受力, 可减重
```

### 2.2 变形云图判读

```
1. 放大系数: 默认自动放大, 注意实际值
2. 变形方向: 是否符合物理直觉?
3. 最大变形位置: 是否在预期位置?
4. 对比允许挠度:
   一般结构: δ < L/500
   精密结构: δ < L/1000
   导轨安装面: δ < 0.02mm
```

### 2.3 模态分析判读

```
1. 前 6 阶: 刚体模态 (约束不足时出现)
2. 第 1 阶弹性模态: 最危险, 必须 > 工作频率 × 1.5
3. 振型观察: 哪个部件在振? → 加强该部件
4. 有效质量比: > 80% 的模态才有意义
```

## 3. 振动测试

### 3.1 测试方法

| 方法 | 设备 | 适用 |
|------|------|------|
| 锤击法 | 力锤+加速度计 | **现场最常用** |
| 激振器法 | 电磁激振器 | 实验室精确测试 |
| 运行模态 | 加速度计阵列 | 在线监测 |

### 3.2 锤击法步骤

```
1. 布置加速度计 (关注关键位置)
2. 力锤敲击 (多点激励)
3. 采集 FRF (频率响应函数)
4. 识别模态参数 (频率/阻尼/振型)
5. 对比 FEA 结果 (误差 < 10% 为合格)
6. 若共振 → 修改结构或加阻尼
```

### 3.3 减振措施实施

| 措施 | 实施方法 | 效果 |
|------|---------|------|
| 橡胶垫 | 设备脚垫 邵氏 40~60A | 隔振 80%+ |
| 阻尼贴片 | 粘在薄壁振动面 | 降低共振幅值 50%+ |
| 加强筋 | 焊接/螺栓连接 | 提高固有频率 |
| 调谐质量 | 附加质量+弹簧 | 消除特定频率 |

## 4. SolidWorks Simulation 操作流程

```
1. 启用插件: 工具→插件→SolidWorks Simulation
2. 新建算例: 右键→新建算例→静应力分析
3. 赋材料: 右键零件→应用材料
4. 夹具: 右键夹具→固定几何体/铰链/滚轮
5. 载荷: 右键载荷→力/压力/重力/离心力
6. 网格: 右键网格→创建→设置尺寸
7. 运行: 右键算例→运行
8. 结果:
   - 应力: 右键结果→定义应力图→von Mises
   - 位移: 右键结果→定义位移图→合位移
   - 安全系数: 右键结果→定义安全系数图
   - 动画: 右键结果→动画
```
