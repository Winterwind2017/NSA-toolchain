## 3. 尺寸链计算

### 3.1 极值法（完全互换）

```
封闭环公差:  T₀ = Σ|T_i|    (所有组成环公差之和)

封闭环基本尺寸:  A₀ = Σ(增环) - Σ(减环)

封闭环上偏差:  ES₀ = ΣES(增环) - ΣEI(减环)
封闭环下偏差:  EI₀ = ΣEI(增环) - ΣES(减环)
```

### 3.2 统计法（大数互换）

```
封闭环公差:  T₀ = √(Σ T_i²)    (概率法，公差更松)

适用条件: 组成环 ≥ 4, 正态分布
```

### 3.3 设计步骤

```
1. 画尺寸链图，确定封闭环（装配精度要求）
2. 标注增环/减环
3. 列方程: A₀ = Σ增 - Σ减
4. 分配公差（等公差法或等精度法）
5. 校核: T₀ ≤ 允许公差？
   不满足 → 压缩关键环公差 / 加调整垫片 / 改配合
```

## 4. 形位公差 (GD&T)

### 4.1 公差项目速查

| 类别 | 项目 | 符号 | 需要基准 | 典型应用 |
|------|------|:----:|:-------:|---------|
| 形状 | 直线度 | — | 否 | 导轨面 |
| 形状 | 平面度 | ▱ | 否 | 安装基准面 |
| 形状 | 圆度 | ○ | 否 | 轴颈 |
| 形状 | 圆柱度 | /○/ | 否 | 精密轴 |
| 方向 | 平行度 | ∥ | 是 | 导轨面间 |
| 方向 | 垂直度 | ⊥ | 是 | 端面×轴线 |
| 方向 | 倾斜度 | ∠ | 是 | 斜面 |
| 位置 | 位置度 | ⊕ | 是 | 孔组 |
| 位置 | 同轴度 | ◎ | 是 | 轴孔 |
| 位置 | 对称度 | ≡ | 是 | 键槽 |
| 跳动 | 圆跳动 | ↗ | 是 | 旋转面 |
| 跳动 | 全跳动 | ↗↗ | 是 | 整体旋转面 |
