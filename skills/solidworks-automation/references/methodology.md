# 方法论：出图审查 / DFM / 自审查

> 这份文件回答的是"**该怎么检查**"，不是"哪个 API 能调"。
> 能力状态以 `swkit registry` 为准；这里所有检查都是**人/模型按步骤做**，
> 不是 swkit 已经自动化的功能。不要把这里的东西说成"已验证能力"。

## 一、工程图审查（GB/T 第一角）

出图后按下面顺序过一遍，每步都要能指出**图纸上的具体位置**：

| 步 | 检查 | 判据 |
|---|---|---|
| 1 | 视图齐全 | 主视/俯视/左视（或剖视）+ 至少一个轴测图；缺少视图 = 结构性缺陷 |
| 2 | 第一角投影 | 俯视图在主视图**正下方**、左视图在**正右方**；对不上就是第三角 |
| 3 | 尺寸链完整 | 每个特征至少一个定位尺寸 + 一个定形尺寸；R 与 Ø 不混用 |
| 4 | 基准与公差 | 有基准符号；关键配合面有公差（未注公差要有技术要求兜底） |
| 5 | 孔表/明细表 | 孔表与模型孔数一致；BOM 与装配体组件数一致 |
| 6 | 技术要求 | 材料、表面处理、未注圆角、去毛刺、热处理——缺项按客户规范补 |
| 7 | 图框信息 | 图号/名称/材料/比例/重量/版本，且与文件名一致 |

**验证自动化能做到哪一步**：swkit 能生成视图与标注、能读回各类标注计数
（`GetDisplayDimensions`、`GetGTolCount`、`GetSFSymbols`…），
**但"这份图是否合规"必须按上表人工判断**。

## 二、DFM 结构化检查（机加工/钣金）

先判断工艺，再逐项检查——不要拿铣削规则套钣金。

| 工艺 | 必查项 |
|---|---|
| CNC 铣削 | 最小内圆角 ≥ 刀具半径；深腔深宽比 ≤ 3:1；薄壁 ≥ 0.8 mm；盲孔底部留平台 |
| 钻孔 | 孔径 ≥ 标准钻径；深径比 ≤ 5（超过要标注）；孔口到边距 ≥ 1.5×孔径 |
| 钣金 | 折弯半径 ≥ 板厚；孔到折弯线 ≥ 板厚 + 半径；展开长度按 K 因子算并核对 |
| 焊接 | 焊缝可达性；焊后加工余量；热变形方向 |

输出格式：**问题 / 位置 / 后果 / 建议改法**四列，不要只给"合格/不合格"。

## 三、生成后自审查（每次建模都做）

1. **特征树与意图一致**：数量、类型、顺序对得上；没有意料外的"空特征"。
2. **几何量自洽**：体积可手算的部件必须手算对照（如 40×25×20 = 20000 mm³）。
3. **文件真的落盘**：存在 + 大小下限 + 文件头签名（`ISO-10303-21` / `%PDF` / `stl`）。
4. **负面对照**：故意用错的标记/方向/类型跑一次，必须失败；不失败说明判据不管用。
5. **截图**：关键视图截一张，肉眼确认没有缺体/破面/错位。

## 四、VBA 宏（本机策略）

- 宏是**最后手段**：能用 swkit 的 verified 配方就不要写 VBA。
- 要跑宏前先做静态检查：确认没有 `Kill`、无文件系统写入、无网络、无 `Shell`。
- 宏只允许在**副本**上跑；原始文件先备份。

## 五、常见"看起来成功"的陷阱

| 现象 | 真相 |
|---|---|
| 返回 `True` | 只说明"调用被接受"，不代表几何变化 |
| 返回一个 `Feature` 对象 | 可能是**空特征**（轮廓为空 / 长度为零） |
| 文件存在且 > 0 字节 | 可能是别的残留文件；要比 mtime + 文件头 |
| 体积不变但特征数 +1 | 典型"建壳无肉"，必须查体积/面数 |
| 装配干涉 = 0 | 可能是**正确**结果（零件本来就是分开的），不是失败 |
